## はじめに

### この資料の目的

この資料は、「脳波（のうは）から、人が快いと感じているか不快と感じているか、また興奮しているか落ち着いているかを推定できるのか」について、これまでの研究で分かっていることを、初めて読む人にも分かるようにまとめたものです。

想定しているサービスは、言葉で気持ちを伝えることが難しい重症心身障害のある方の状態を、額（ひたい）に付けた小さな脳波計で測り、支援者や家族に表示するものです。そのため、次の4つの分野を中心にまとめています。

1. 脳波で感情を推定する研究（どこまでできているか、どんな条件で精度が変わるか）
2. 額（前額部）の脳波から計算できる指標
3. 重度の障害のある方の快・不快を評価してきた研究
4. 似たことをしている製品・サービス

### 読み方

- まず「総括」で全体像をつかみ、気になる部を読む、という使い方を想定しています。
- 専門用語は、初めて出てくるところで説明しています。まとめて確認したいときは、付録B（用語集）を見てください。
- 数字には、どんな条件で得られた数字かを、できるだけ一緒に書いています。脳波の研究では、同じ方法でも評価の仕方によって数字が大きく変わるためです（§3 で説明します）。

### 最初に知っておくとよい言葉

本文でくり返し出てくる言葉です。詳しくは付録B（用語集）にあります。

- **脳波（EEG）**: 頭の表面に置いた電極で記録する、脳の電気活動。脳の表面（大脳皮質）の多数の神経細胞の活動が重なったもの。
- **電極・チャンネル**: 電極は頭や体に付けて電気信号を拾う部品。記録する信号の系統の数をチャンネルと呼ぶ（電極1個とその基準で1チャンネル）。
- **Hz（ヘルツ）と α 波・β 波など**: 脳波は速さ（周波数、1秒あたりの波の数＝Hz）の違う波が重なってできている。周波数の範囲ごとに δ 波（1〜4 Hz）、θ 波（4〜8 Hz）、α 波（8〜13 Hz）、β 波（13〜30 Hz）、γ 波（30 Hz 以上）と呼ぶ（§6.1）。
- **電極の位置（Fp1・Fp2・Fz など）**: 国際的な配置法（10-20法）での電極の位置の名前。Fp1 は左の額、Fp2 は右の額、Fpz は額の真ん中、Fz は額と頭頂の間の前寄りの正中線（第3部の冒頭）。
- **筋電・眼電**: 筋肉や眼球の動きが出す電気信号。頭の表面の電極に混ざる（§10.4）。
- **fMRI・PET**: 脳の血流や代謝を画像で測る方法。脳の奥の活動も測れる。
- **BCI**: 脳の信号で機器を操作したり、状態を読み取ったりする仕組み（brain-computer interface）。
- **査読・プレプリント**: 査読は、論文を専門家が審査してから雑誌に載せる仕組み。プレプリントは、査読の前に公開された論文（この資料では「査読前」と書く）。
- **メタ分析・系統的レビュー・総説**: メタ分析は複数の研究の結果を統計的にまとめる方法。系統的レビューは決まった手順で文献を集めて整理したもの。総説はある分野の研究をまとめた論文。
- **有意（p 値）**: 統計の検定で「偶然では起こりにくい差」と判断されたこと。p 値が小さいほど偶然では起こりにくい。
- **意識障害の状態**: 目は開くが周りに反応しない「植物状態（VS／無反応覚醒症候群 UWS）」と、わずかに反応がある「最小意識状態（MCS）」がある。
- **PIMD・重症心身障害**: 最重度の知的障害と重い運動障害の重複（海外の用語）／重度の肢体不自由と重度の知的障害の重複（日本の用語）（第4部の冒頭）。

# 総括

各部で紹介している研究の報告を、事実だけで短くまとめます。

### 感情と脳について（第1部）

- 研究では、感情を「快か不快か（valence、バレンス）」と「興奮しているか落ち着いているか（arousal、覚醒度）」の2つの軸で表すことが多い [Russell 1980]。
- 「快そのもの」は脳の奥の小さな領域が生むとする総説がある [Berridge & Kringelbach 2015]。音楽による感情では、扁桃体・海馬・聴覚皮質・報酬系が活動した（47研究のメタ分析）[Koelsch 2020]。
- 音楽による快の強さは、心拍や汗などの興奮の指標と強く正に相関した [Salimpoor 2009]。

### 脳波による感情推定の研究について（第2部）

- 脳波による感情検出の論文（285本）を調べたレビューは、論文が大きく増えている理由として、無線の脳波計の普及と機械学習の進歩を挙げている [Al-Nafjan 2017]。主な公開データセットには、2012年の DEAP、2015年の SEED などがある（§4・§5）。
- 報告される精度は、評価の仕方（§3.2）によって違う。
  - 同じ人・同じ回のデータで学習とテストをすると、3択で 84〜94% という報告がある [Zhong 2022]。
  - 同じ人でも別の回（1週間以上あと）のデータでテストすると 67〜78% だった [Zheng, Zhu & Lu 2019]。5日間の研究では、1日分で学習すると別の日で約60%だった [Liu S 2018]。
  - 学習に使っていない人でテストすると、手法によって 57〜85% だった。高い方の手法は、テストに使う人の正解なしのデータを学習に使っている [Zhong 2022]。
  - 本人が付けた評価を正解にし、学習に使っていない人でテストすると、4つの手法のどれも「いつも多い方を答える」基準を超えなかった（DEAP・AMIGOS・DREAMER）[Kukhilava 2025]（査読前）。同じ試行が学習とテストにまたがらない条件の別の研究では、別の人での DEAP の快不快の2択が 49.58〜57.78% だった [Liu H 2024]（査読前）。
- DEAP を使った研究101本の約87%に方法上の誤りがあった。1つの試行を細かく区切ってから学習とテストに分けると数字が高く出て、スイカから取った「脳波」でも同じように高い数字が出た [Khan 2025]（査読前）。
- 脳波の特徴量に含まれる感情の情報の大部分は表情筋の活動が混ざった結果だ、と結論した研究がある [Soleymani 2016]。頭の中で発声する課題では、無意識の表情筋の活動が感情の判別のパターンに寄与していた（5名で筋電を同時記録）[Tang 2026]。
- 個人に合わせて調整すると精度が上がったという報告がある（§11）。日をまたぐ評価では、6名・8日間の研究で、1回分で学習して残りの回（最大8日後まで）でテストすると 25.16〜39.70% で、論文が示すチャンスの上限（約28〜29%）の前後だった [Lan 2020]。
- 大規模な事前学習モデル（基盤モデル）の CBraMod は、FACED の9択で 0.551（事前学習なしの最良は 0.489）だった [Wang J 2025]。基盤モデルを比べたベンチマークでは、DEAP の快不快の最高が 0.533（チャンス 0.50）だった [Lu Z 2026]（査読前）。額の1〜2チャンネルで検証した例は見つからなかった。
- 額の電極だけを使った研究には、本人が最も強く快・不快を感じた試行だけを選んだ条件で97%という報告がある [Abdel-Hamid 2023]。32チャンネルで試行単位に分けた評価では、DEAP の2択で約59〜62%だった [Ding 2023]。

### 額の脳波で得られる指標について（第3部）

- α 波（8〜13 Hz）の強さは、安静時の覚醒度の指標として使えると結論した研究がある [Barry 2007]。鳥肌の立つ曲の研究では、α 波の強さに快の効果はなかった [Chabin 2020]。
- 額は目と眉に近く、眼球の動きの信号は主に δ 波・θ 波の帯域に、筋電は β 波・γ 波の帯域に入る [Smith 2017; Goncharova 2003; Whitham 2007]。
- 左右の前頭部の α 波の差（FAA）は、740人の研究で、接近動機づけの指標としての妥当性が、状態の指標としても性格の指標としても支持されなかった [Paul 2025]。

### 重度障害のある方の研究について（第4部）

- 快・不快の表し方は人によって大きく違い [Petry & Maes 2006]、標準化された評価法はないとされている [Adams & Oliver 2011]。
- 観察する人に「どの刺激を出したか」を知らせると、判断がより極端になった [Hogg 2001]。
- 生理指標の報告: 提示から6秒の心拍は不快な刺激で低かった [Vos 2012]。心拍の上昇は、苦痛を示す場面でも喜びを示す場面でも見られた [Kildal 2021]。皮膚コンダクタンスは楽しい刺激で最も高く、怒りの刺激でも高かった [Krämer & Zentel 2020]。
- 重度の重複障害の子ども2名で、心拍などから快・中立・不快の3択を推定した研究は 0.74（いつも多い方を答える基準 0.65）、覚醒しているかの推定は 0.77（同 0.65）だった [Hammann 2022]。
- 重症心身障害のある方が好きな動画・音楽を見聞きしたときの反応を、額の脳波で評価した査読論文は、今回の検索の範囲では見つからなかった。

### 脳波以外の信号について（第5部）

- ストレスの推定では、本人専用のモデルが95%超、他の人のデータで作ったモデルが42.5%だった [Nkurikiyeyezu 2020]。
- 同じ物語を見聞きした人どうしで心拍の動きが同期し、意識障害の患者では低かった [Pérez 2021]。

### 製品・サービスについて（第6部）

- 額の1チャンネルで「好き・興味・ストレス」などを表示する製品（感性アナライザ）が、2016年時点の公式記事に載っている。精度を示した査読付きの検証論文は見つからず、現在の提供状況も確認できなかった。
- 重症心身障害のある方向けに、脳波を使った商用サービスは見つからなかった。表情・心拍などを使う研究開発は国内にある（四国大学、横浜市立大学など）。
- 一般の人の表情データで学習させた感情モデルは重症児には使えなかった、と報告されている（四国大学の報告書）。

### 倫理について（第7部）

- ヘルシンキ宣言・CIOMS の指針・国内の指針は、同意できない方の研究参加について、本人に利益が見込まれるか最小のリスク・負担の場合に限ることや、本人の拒否を尊重することなどを定めている [WMA 2024; CIOMS 2016; 生命・医学系指針 2023]。

### 民生用の脳波計について（付録A）

- 民生用の脳波計を使った研究は916件あり、民生用は研究用より信号対雑音比がかなり低いとレビューされている [Sabio 2024]。医療用と民生用を額（Fp1）で比べた研究は、医療用がデータの品質・信頼性で明確な利点をもつと結論している [Ratti 2017]。

# 第1部 感情と脳の基本

この部では、研究者が「感情」をどう扱っているか、快や不快が脳のどこで生まれると考えられているかをまとめます。第2部以降の研究を読むための前提になります。

## 1. 感情をどう表すか

### 2つの考え方

研究で感情を扱うとき、大きく2つの考え方があります。

- **種類で分ける考え方（離散モデル）**: 喜び・悲しみ・怒り・恐怖・嫌悪・驚きのような「基本感情」に分けて扱う。
  - 脳波のデータセットでは、SEED（快・中立・不快の3種類）[Zheng & Lu 2015]、SEED-IV（喜び・悲しみ・恐怖・中立の4種類）[Zheng 2019] がこの考え方。
- **軸で表す考え方（次元モデル）**: 感情を、いくつかの軸の上の位置として表す。代表は Russell の円環モデルで、感情を「**valence（快–不快）**」と「**arousal（覚醒–鎮静。興奮しているか落ち着いているか）**」の2つの軸の平面に並べる [Russell 1980]（書誌）。
  - 例えば「喜び」は快で覚醒が高い、「リラックス」は快で覚醒が低い、「怒り」は不快で覚醒が高い、という位置になる。
  - DEAP・DREAMER・AMIGOS・MAHNOB-HCI などのデータセット（§5）は、参加者に valence と arousal を自分で評価してもらい、それを正解（ラベル）にしている [Koelstra 2012; Katsigiannis & Ramzan 2018; Miranda-Correa 2021; Soleymani 2012]。
  - 自己評価には、表情の絵を並べた尺度（SAM: Self-Assessment Manikin）がよく使われる [Li X 2022]（本文）。

### 「近づきたい気持ち」（接近と回避）

- Davidson は、左の前頭部を「近づく（接近）」、右の前頭部を「遠ざかる（回避）」に関係する行動・感情に対応づけた [Davidson 1992]（抄録）。
- Harmon-Jones らは、左の前頭部の相対的な活動は「快い感情」ではなく「近づきたい気持ち（接近動機づけ）」に対応すると論じた。怒りのように「不快だが相手に向かっていく」感情でも左が優位になるためである [Harmon-Jones 2010]（抄録）。
- 前頭部の左右差を、脳刺激などで人為的に変えた研究のレビューは、左右差と接近・回避の関係について、より因果的な見方を支持すると結論している [Kelley 2017]（抄録）。
- 前頭部の左右差は、その人の性格のような「変わりにくい特徴」としての役割と、その時々の「状態の変化」としての役割の両方をもち、両者を分けて解析すべきとされている [Coan & Allen 2004]（抄録）。
- その後の研究の多くが、左右差の統計的な役割（予測するものか、結果か、間に入るものか）を明示していないと指摘されている [Reznik & Allen 2018]（抄録）。
- 詳しくは §19（FAA）で扱います。

### 自己評価と体の反応の関係

- DEAP の著者は、自己評価と脳波の帯域の強さの相関は、平均すると ±0.1 を超えることはまれで、人によっては ±0.5 程度の相関が出ることもあったと報告している [Koelstra 2012]（本文）。
- 既存の感情データセットの参加者は平均21〜35歳の若い成人が中心で、それで作ったモデルが他の集団にそのまま当てはまるとは限らない、と記されている [Wu 2023]（本文）。同じ論文は、「刺激（動画など）の感情＝本人が感じた感情」という前提は、個人差、反応の弱さ、1回の試行の中での変化のために不正確だと記している。
- 表情から感情を推測するときには、文脈によって意味が変わり、表情と感情が一対一に対応しないという限界があるとするレビューがある [Barrett 2019]（書誌）。
- 個別の感情（怒りだけ、恐怖だけなど）に対応する特定の脳部位は見つからない、としたメタ分析がある [Lindquist 2012]（書誌）。

## 2. 快・報酬・嫌悪は脳のどこで生まれるか

### 音楽による快と脳の「報酬系」

脳には、食べ物やお金などのご褒美（報酬）に反応する仕組みがあり、「報酬系」と呼ばれます。音楽の快についての研究では、次のことが報告されています。

- 音楽で鳥肌（chills）が立つほどの快感のとき、その強さに応じて、腹側線条体・中脳・扁桃体・眼窩前頭皮質などの血流が変化した。鳥肌には、心拍・**筋電（筋肉の電気信号）**・呼吸の変化が伴った（PET による測定、音楽経験者10名）[Blood & Zatorre 2001]（抄録＋本文、要約経由）。
- 音楽の感情のピークで、線条体でドーパミン（報酬に関わる脳内物質）が放出された。期待している段階では尾状核、ピークの段階では側坐核が関わっていた [Salimpoor 2011]（抄録）。
- 連続して評価してもらった快の強さと、交感神経の興奮の指標（心拍・呼吸・皮膚の電気活動・体温など）が強く正に相関した。快を感じなかった人では興奮の指標も上がらなかった（26名）[Salimpoor 2009]（抄録）。
- 音楽と食べ物による快は、腹内側前頭前野・腹側線条体・島という共通の領域を使っていた（38研究・703名のメタ分析）[Mas-Herrero 2021]（抄録）。
- 音楽による感情では、扁桃体・海馬・聴覚皮質・報酬系（線条体、前帯状皮質、眼窩前頭皮質）が活動した（47研究・944名のメタ分析）[Koelsch 2020]（抄録）。同様の総説もある [Koelsch 2014]（抄録）。
- 音楽の快は、音の流れの「予測」と報酬系のやりとりから生まれるとする総説がある [Vuust 2022]（抄録）。
- 音楽をご褒美と感じる度合いには大きな個人差があり、音楽だけに快を感じにくい人（特異的音楽無快感症）もいるとする総説がある [Mas-Herrero 2026]（抄録）。

### 「快そのもの」と「欲しい気持ち」

- 「快そのもの（liking）」は脳の奥の小さな領域（hedonic hotspot）が生み、「欲しい気持ち（wanting）」はもっと広い仕組みが生むとする総説がある。ドーパミンの系は快そのものを生まない可能性があると述べている [Berridge & Kringelbach 2015]（抄録）。

### 脳波でとらえるポジティブな感情

- ポジティブな感情の脳波の指標として、前頭部の外側の α 波の左右差、運動野の β 波、ご褒美を受けたときの脳の反応（報酬陽性電位）を整理した総説がある。いずれも課題やフィードバックがある場面での指標とされている [Gable 2021]（抄録）。

### 音楽の快と脳波（個別の研究）

- 協和音の快い曲と、それを電子的に不協和にした不快な曲を比べると、快い曲で**前頭部の正中線の θ 波（Fmθ）**が強くなり、不快な曲では心拍が下がった [Sammler 2007]（抄録）。
- 音楽の快の評価は、**右の側頭部と前頭部の θ 波のタイミングのそろい方（位相同期）**と関係していた [Ara 2020]（抄録）。聞き慣れた曲と初めての曲では、快に関わる θ 波のつながり方が違った [Ara 2021]（抄録）。
- 右の聴覚皮質に θ 波のリズムの弱い電流を流す（経頭蓋交流電気刺激）と、偽の刺激に比べて、初めて聴く単純な旋律の好みの評価が上がった。β 波のリズムでは上がらなかった（24名）[Ara 2026]（抄録）。
- 本人が選んだ鳥肌の立つ曲を256チャンネルの脳波で調べた研究（18名）[Chabin 2020]（本文の一部）:
  - 快と覚醒が強いほど、右の前頭前野の θ 波が強かった。
  - 前頭部の β 波と α 波の比は、鳥肌のときに高かった。
  - **α 波の強さには、どの部位でも快の効果がなかった。前頭部の α 波の左右差にも効果がなかった。** 著者は「前頭部の α 波の左右差は、感じた快を反映しなかった」と結論している。
  - 筋電は個別に検討しておらず、著者は、評価のための体の動きが影響した可能性に触れている。
- 旋律の「意外さ」と快の評価が、前頭部の β 波・γ 波の強さと対応し、θ 波とは対応しなかった [Ueno & Shimada 2024]（抄録）。
- 本人が選んだ好きな曲で、額と前頭部の正中線（Fp1・Fp2・Fz、乾式電極）の θ 波と遅めの α 波が、無音のときより強くなった。モーツァルトや「集中用」の音楽では強くならなかった。θ 波は好みの強さと相関した。左右差には有意な差がなかった。眼や筋肉の信号の処理は書かれていない（28名）[Tseng 2021]（本文の一部）。

### 不快・嫌悪と脳

- 嫌な音を聞かせると、扁桃体と聴覚皮質が反応した。扁桃体は、音の物理的な特徴と、主観的な不快さの両方を表していた（fMRI）[Kumar 2012]（抄録）。
- 嫌な音を白色雑音と比べると、扁桃体、脳幹、側坐核、島、右の聴覚野などの血流が増えた（PET、嫌な音に敏感な8名）[Zald & Pardo 2002]（抄録）。

# 第2部 脳波で感情を推定する研究

この部は、この資料の中心です。脳波から感情を推定する研究が、どう進められ、どこまでの成果を報告しているかを、研究の流れ・歴史・主な論文・評価の問題点・個人への最適化・少数の電極での研究の順にまとめます。

## 3. 研究の進め方と、評価の分け方

### 3.1 研究の基本的な流れ

脳波で感情を推定する研究の典型的な手順は次のとおりです。ウェアラブルの生理信号による感情認識のレビューは、多くの論文が「参加者募集→刺激の準備と注釈→信号の収集と処理→自己評価→モデルの学習と検証」という同じ手順をとると報告している [Saganowski 2023]（抄録）。

1. **刺激を見せる**: 感情を引き起こす動画・音楽・画像などを参加者に見せる（聞かせる）。
2. **脳波を記録する**: 頭に付けた電極で脳波を記録する。§5 の公開データセットでは、1〜62チャンネルの機器が使われている。
3. **正解（ラベル）を決める**: 「このとき参加者は快だった／不快だった」という正解を決める。決め方は主に2通り。
   - 参加者自身の評価（自己評価）。例: 動画を見た後に「快–不快」を9段階で答える。
   - 刺激の種類。例: 「楽しい動画」を見ている間は「快」とみなす。
4. **特徴量を計算する**: 脳波から「α 波の強さ」のような数値（特徴量）を計算する（§6）。
5. **推定のモデルを学習させる**: 特徴量と正解の組をたくさん集め、機械学習で「特徴量から正解を当てる」モデルを作る（§7）。
6. **評価する**: 学習に使っていないデータでモデルを試し、何%当たるかを調べる。

### 3.2 評価の分け方で数字が変わる

6の「評価」で、どのデータを学習に使い、どのデータをテストに使うかを決めます。この分け方によって報告される数字が大きく変わることが報告されています（§9・§10）。

| 分け方 | 何をするか | 例 |
|---|---|---|
| 同じ人・同じ試行の中で区間をランダムに分ける | 同じ人が見た同じ動画から切り出した数秒ずつの区間を、ランダムに学習用とテスト用に分ける | 1本の動画の90%の区間で学習し、残り10%でテスト |
| 同じ人・試行単位で分ける | 同じ人の中で、動画（試行）ごと丸ごと学習用かテスト用かに分ける | 15本のうち9本で学習し、6本でテスト |
| 同じ人・別の日で分ける | ある日の記録で学習し、別の日の記録でテストする | 1回目の記録で学習し、2回目でテスト |
| 別の人で分ける | 学習に使っていない人でテストする。1人ずつ順にテストに回す方法（LOSO: leave-one-subject-out）が代表 | 15人のうち14人で学習し、残り1人でテスト |

- **同じ試行の中で区間をランダムに分けると、学習とテストに「ほぼ同じ時間帯のデータ」が入る**ので、数字が高く出やすいと指摘されている [Li X 2022; Khan 2025]（§10）。
- 交差検証（データをいくつかに分け、順番にテスト用に回して平均をとる方法）をしていても、同じ試行のデータが学習とテストの両方に入る研究がある、と指摘した研究がある [Jatupaiboon 2013]（本文）。

### 3.3 比べる基準

- **チャンス**: でたらめに答えたときの正解率。2択なら50%。
- **いつも多い方を答える基準（多数派ベースライン）**: 例えば、正解の70%が「快」なら、いつも「快」と答えるだけで70%当たる。正解の数が偏っていると、チャンスより高くなる。
  - DEAP の valence の2択では、快と不快を分ける境目の決め方が論文によって7通りあり、境目によって多い方の割合が56.5%にも72.2%にもなる。このため「チャンス＝50%」として比べるのは誤りだと指摘されている [Kukhilava 2025]（査読前、本文）。

## 6. 脳波から何を計算するか（特徴量）

脳波はそのままでは扱いにくいので、多くの研究では「特徴量」と呼ぶ数値に変えてから推定に使います。

### 6.1 周波数の帯域ごとの強さ

脳波は、速さ（周波数）の違う波が重なってできています。研究では、周波数の範囲ごとに名前を付けて扱います。

| 名前 | 周波数の範囲（目安） | 文献で結びつけられていること |
|---|---|---|
| δ（デルタ）波 | 1〜4 Hz | 深い睡眠 [Kane 2017; Jiang 2019] |
| θ（シータ）波 | 4〜8 Hz | リラックス・瞑想 [Jiang 2019]。集中や眠気 [Klimesch 1999; Cavanagh 2014] |
| α（アルファ）波 | 8〜13 Hz | 目を閉じて落ち着いているときに強く、注意を向けると弱まる [Kane 2017] |
| β（ベータ）波 | 13〜30 Hz | 能動的な思考 [Jiang 2019]。運動や触覚の刺激で弱まる前頭中心部の律動 [Kane 2017] |
| γ（ガンマ）波 | 30 Hz 以上 | 頭の表面では筋肉の活動の周波数と重なる [Muthukumaraswamy 2013] |

- 帯域の境目は文献によって少しずつ違う [Kane 2017; Donoghue 2020]。
- 「帯域の強さ（帯域パワー）」は、その周波数の波がどれだけ強く含まれているかを表す。DEAP の基準の手法は 3〜47 Hz の強さと左右差を使った [Koelstra 2012]。
- **DE（differential entropy）**: SEED 系の研究で標準的に使われる特徴量 [Duan 2013]。一定の仮定のもとでは、帯域の強さの対数と同じものになる [Zheng & Lu 2015]（本文）。SEED の公式ページは、DE を時間方向になめらかにして（移動平均や線形動的システム LDS で）配布していると記している（https://bcmi.sjtu.edu.cn/home/seed/ ）。

### 6.2 その他の特徴量

- **左右差の特徴**: 左右対の電極で DE の差（DASM）や比（RASM）を、前後の電極で差（DCAU）をとる [Zheng & Lu 2015]。
- **時間の波形の特徴**: Hjorth パラメータ（波の強さ・速さ・複雑さ）[Hjorth 1970]（書誌）、高次交差（波がゼロを横切る回数などを使う特徴）[Petrantonakis & Hadjileontiadis 2010]。
- **フラクタル次元**: 波形の複雑さ。音楽の連続評価の研究で、帯域の強さをわずかに上回った [Thammasan 2016]（抄録）。リアルタイムの推定にも使われた [Liu 2010]（抄録）。
- **複雑さ（エントロピー）や、電極どうしのつながり（コネクティビティ）**も使われる [Li X 2022]。

### 6.3 どの特徴量がよいか

- 33本の研究で使われた特徴量を同じデータで比べた研究では、(i) 複数の特徴を組み合わせて選ぶ方法が1つずつ選ぶ方法よりわずかに良く、(ii) 高次交差や Hjorth などが単純な帯域の強さより有利で、(iii) よく選ばれた電極は頭頂部・中心頭頂部だった [Jenke 2014]（抄録）。
- 被験者をまたいだ評価で特徴量を比べた研究では、β 波の帯域の Hjorth の「速さ」が単独では最も良かった。DEAP で 59.06%、SEED で 83.33% [Li X 2018]（抄録）。
- 62チャンネル・映画クリップ（正6本・負6本、6名）の研究で、帯域ごとに見ると、δ 波 62.16%、θ 波 77.36%、α 波 85.53%、β 波 83.61%、γ 波 84.23%、全帯域 87.53% だった。時間窓は 0.5〜2 秒を比べて1秒が最も良かった。時間方向になめらかにする処理（LDS）で 82.88% から 87.53% に上がった（同じ人・試行単位で分けた評価）[Wang XW 2014]（本文）。

| 時期 | 主な手法 | 例 |
|---|---|---|
| 〜2014年ごろ | 古典的な機械学習（SVM、k 近傍法、線形判別分析、ナイーブベイズなど） | DEAP・MAHNOB の基準の手法 [Koelstra 2012; Soleymani 2012] |

| 2016年〜 | 別の人・別の日のデータの違いを小さくする手法（ドメイン適応、転移学習） | [Zheng & Lu 2016; Jin 2017; Zhao 2021] |
| 2022年〜 | 時間・空間の特徴をとらえる専用の構造、注意機構、Transformer | TSception [Ding 2023]、ACRNN [Tao 2023]、EEG Conformer [Song Y 2023] |

## 10. 評価方法の問題を指摘した研究

高い精度の報告について、評価の手順に問題があると指摘する研究が増えています。

### 10.1 学習とテストへのデータの「漏れ」

テスト用のデータの情報が学習に紛れ込むことを「漏洩（リーク）」と呼びます。

- **ブロックデザインの問題** [Li R 2021]（arXiv 版本文＋査読版の抄録）: 画像の種類を、同じ種類を続けて見せる方式（ブロックデザイン）で記録した脳波の再解析。
  - 元のデータでは LSTM 93.7%、SVM 94.0%、CNN 97.4% の高い精度が出た。
  - 同じ画像を種類を混ぜたランダムな順番で記録し直すと、どの手法もチャンスになった。
  - ランダムな順番のデータに、まとまり（ブロック）ごとの正解を付けると、高い精度が「出てしまった」。
  - 元のデータに低い周波数を除くフィルタをかけると、約93%から約32%に下がった。
  - 著者らは、高い精度の正体は、まとまりごとのゆっくりした状態の変化をとらえていたことだと結論している。
- **DEAP を使った101本の論文の点検** [Khan 2025]（査読前、本文）:
  - 約87%に、少なくとも1つの方法上の誤りがあった（区間の切り方による漏洩、データ全体での特徴の選択、テストデータでの設定の調整、正解の偏りの無視など）。
  - 2択の valence で、1つの試行を細かい区間に切ってから分けると、切らない場合の約53%から、6分割で90%超、60分割でほぼ100%になった。試行単位で分けた場合は約52%のままだった。
  - **スイカから記録した「脳波」にでたらめな正解を付けたデータでも、同じように高い数字が出た。**
  - データ全体で特徴を選ぶと 77.4%（正しい手順では 62.2%）、テストデータで設定を調整すると 84.4%（正しくは 62.5%）になった。
- **深層学習6手法での再現** [Lei 2025]（ワークショップ論文、本文）: DEAP の3択で、漏洩なしでは valence 平均 0.42、arousal 0.28。漏洩があると 0.69、0.68 になり、valence は少なくとも35.71%上がったと記載されている。CNN 系ほど影響が大きかった。
- テストに使う試行で学習の区切りを選ぶと、SEED の同じ回で +6.24ポイント、別の回で +2.75〜4.47ポイント数字が上がった [Suo 2026]（査読前、抄録）。
- レビュー論文は、区間を無作為に分ける方式を「誤った方法であり、用いるべきではない」と明記している [Li X 2022]（本文）。
- 別の人でのモデルでも、データの分け方を誤ると誤り率が35〜3900%小さく見積もられた（公開データ5種）[Kamrud 2021]（抄録）。区間単位で分けると新しい人での性能が過大に見積もられた [Brookshire 2024]（抄録）。まとまりの構造を考慮するかで、正解率が最大30.4%変わった [Schroeder 2025]（抄録）。
- TSception の著者は、漏洩を避けるために試行単位の分割を採用したと本文に明記している。その条件では DEAP の2択で約59〜62%だった [Ding 2023]（本文）。

### 10.2 正解（ラベル）の決め方

- 多くのデータセットの正解は、刺激の後の本人の評価、または刺激の種類で決めたもの（§5）。
- 1つの試行の中でも感情は時々刻々と変わるので、試行全体の正解を細かい区間すべてに割り当てると、正解の誤りが増えると指摘されている [Li X 2022]。
- DEAP の著者は、valence と「好き」の評価の相関の分布がとても似ていると指摘している [Koelstra 2012]。
- 同じ刺激を見た人どうしの脳波をそろえることを手がかりにした手法（CLISA）がある [Shen 2023]（抄録）。

### 10.3 刺激そのものや視線の情報

- DEAP では、脳波を使わず動画の内容の特徴だけで、脳波以上の成績が出た。MAHNOB では、視線のデータが脳波より高い成績だった（§8.2）。

### 10.4 表情筋・眼球運動の信号の混入

頭の表面の電極には、脳の信号だけでなく、顔や頭の筋肉の電気信号（筋電）や、眼球の動きの信号（眼電）も入ります。これらを「アーチファクト」と呼びます。

- 顔の表情と脳波を同時に解析した研究は、**脳波の特徴量に含まれる感情の情報の大部分は、表情筋の活動が混ざった結果**だと結論した。それでも脳波には補完的な情報が残るとしている [Soleymani 2016]（抄録）。
- 声に出す発声（14名）と頭の中だけの発声（21名）で5種類の感情を判別した研究（64チャンネル）[Tang 2026]（抄録）:
  - 正解率は、声に出す 78.1%、頭の中だけ 36.4%（チャンス 20%）。
  - 判別に重要だったのは、高い γ 波（50〜100 Hz）と、外側の側頭部の電極（T7・T8 とその周り）。
  - 5名で顔の筋電を同時に記録すると、頭の中だけの発声でも無意識の表情筋の活動があり、これらのパターンに寄与していた。
  - 著者は、観察した筋電のパターンが、感情の判別の研究でよく報告される脳波のパターンにとても似ていると懸念を示している。
- 筋電は振幅が大きく周波数の範囲が広く、心理的な変化にも敏感に反応するので、周波数を扱う脳波研究すべての推論を脅かすとしたレビューがある。弱い筋電でも、α 波ほどの低い周波数まで頭全体で検出できた [Shackman 2009]（抄録）。
- 頭の周りの筋肉の信号は、認知・感情の脳波研究にとって重大な脅威になるとし、独立成分分析（ICA）による除去の有効性についての議論を整理した研究がある [McMenamin 2010; McMenamin 2011]（書誌／抄録）。
- 頭の筋肉の活動のため、電極のレベルでは脳由来の γ 波（30 Hz 超）を直接調べられなかった、という報告がある。空間フィルタを使った発生源の解析で、筋肉と眼球運動の混入を効率よく除けた [Hipp & Siegel 2013]（抄録）。
- 目を閉じて感情を想像する課題の脳波を分解すると、15〜200 Hz の広い帯域の強さを変える成分が、脳・頭皮の筋肉・おそらく眼球運動の3種類に分かれた。脳由来の成分と、想像した感情の快不快との間に関係があった [Onton 2009]（抄録）。
- 前額部・側頭部の筋電は、前額部で 20〜30 Hz、側頭部で 40〜80 Hz に強さのピークがあり、弱い力（最大の15%）でも 12 Hz 以上（人によっては 8 Hz 以上）に検出された [Goncharova 2003]（抄録）。
- 筋肉を薬で完全に弛緩させると、20 Hz 以上の強さが10〜200倍違い、頭の表面の脳波の 20 Hz 以上の大半は筋電に由来するとされた（2名）[Whitham 2007]（抄録）。
- DEAP の著者自身も、valence と相関した側頭部の γ 波の増加について、筋電の可能性を明記している [Koelstra 2012]。
- 音楽の鳥肌の快感そのものに、筋電の変化が伴っていた [Blood & Zatorre 2001]。

# 第3部 額（前額部）の脳波から得られる指標

この部では、額に付けた1〜2個の電極の脳波から計算できる指標について、研究で報告されていることをまとめます。

**電極の場所の呼び方**: 脳波の電極の位置は、国際的に決められた「10-20法」という配置で呼びます。額の位置は Fp（frontal pole、前頭極）で、左の額が Fp1、右の額が Fp2、真ん中が Fpz です。額と頭頂の間の前寄りの正中線は Fz、頭のてっぺんは Cz です。数字が奇数なら左、偶数なら右を表します [Acharya 2016a; Rojas 2018]。Fp1・Fp2 の下には、脳の前頭極（前頭前野の一番前の部分）があると対応づけられています [Rojas 2018]（本文）。

**額の脳波の特徴**: 額は目と眉のすぐ上にあるので、瞬きや眼球の動きの信号（眼電）、眉や額の筋肉の信号（筋電）が入りやすい場所です（§10.4、§17）。

## 16. α 波の強さ

α 波（8〜13 Hz）は、目を閉じて落ち着いているときに強く出て、目を開けたり注意を向けたりすると弱まる脳波です [Kane 2017]。

**覚醒度との関係**
- 28名で、目を閉じているときの皮膚の電気の流れやすさ（汗の量を反映する、興奮の指標）と、平均の α 波の強さは負に相関した。目を開けると、皮膚の指標は上がり、δ 波〜β 波の強さは下がった。著者は、α 波の強さは目を開けていても閉じていても安静時の覚醒度の指標として使えると結論した [Barry 2007]（抄録）。
- 興奮する画像（16名）を見たときに、刺激の 0.6〜1 秒後に後頭部・前頭部の α 波と遅めの β 波が弱まった。著者は、これは感情の「覚醒度」を反映すると結論している [Schubring & Schupp 2019]（抄録）。

**快・不快との関係**
- 本人が選んだ鳥肌の立つ曲では、どの部位でも α 波の強さに快の効果がなかった [Chabin 2020]（§2）。
- 好きな曲で、額と前頭部の正中線（Fp1・Fp2・Fz）の遅めの α 波が、無音のときより**強くなった** [Tseng 2021]（§2）。
- 意識障害の患者21名で、好きな音楽を聴いたときに前頭部の α 波が強くなったのは7名（植物状態3名、最小意識状態4名）だった [O'Kelly 2013]（抄録）。

**測定の再現性**
- 370名を8回測った研究で、α 波の強さの再現性（ICC。1に近いほど、測るたびに同じ値が出る）は 0.87〜0.94 で、左右差（§19）の 0.56〜0.88 より高かった。この値は F3/F4・P3/P4 などの部位での、同じ日の中の短期の再検査の値 [Metzen 2022]（本文）。

**額で測るときの注意として報告されていること**
- 民生用・研究用の機器のどちらでも、前頭部では、目を開け閉めしたときの α 波の変化が有意でなかった [Mikhaylov 2024]（付録A）。
- 平均の電極を基準にした場合など、基準の取り方によっては、後頭部の α 波が前頭部に映り込む問題があると記されている [Smith 2017]（本文）。
- 耳たぶを含む基準の場所にも、前頭部と同じくらいの α 波があることが示された [Hagemann 2001]（抄録）。
- 単一の乾式電極の機器でも、目を閉じると相対的な θ 波が下がり α 波が上がる、という予想どおりの変化をとらえられた（小児23名）[Johnstone 2012]（抄録）。

**個人ごとの α 波の周波数**
- α 波の周波数には個人差があり、その人の α 波の周波数（IAF: individual alpha frequency）を基準に、α 波・θ 波の範囲を人ごとに調整することが提案されている。眠気が進むと、速めの α 波が弱まり θ 波が増える [Klimesch 1999]（抄録）。
- IAF の求め方には、ピークの周波数（PAF）と重心の周波数（CoG）があり、どちらにするかの合意は乏しい [Corcoran 2018]（抄録）。

## 17. θ 波・β 波・比率の指標・γ 波

**θ 波（4〜8 Hz）**
- θ 波の増加は、集中（前頭部の正中線 Fz の θ 波）とも、眠気（全体的な θ 波の増加）とも結びつけられてきた [Klimesch 1999; Cavanagh 2014]。
- 眼球の動きの信号の強さの大半は、δ 波・θ 波の帯域にある [Smith 2017]（本文）。
- 動画を見ているときの瞬きは、注意がいらない場面に合わせて起こり、注意が必要な場面では抑えられる [Nakano 2009]（抄録）。
- 映画の抜粋を見たときに、Fp1・Fp2 の θ 波の左右差が、感情の種類によって違った（眼電の補正あり）[Zhao 2018]（§13.1）。

**β 波（13〜30 Hz）**
- 快い刺激では頬の筋肉（大頬骨筋）、不快な刺激では眉の筋肉（皺眉筋）の筋電が変化し、**眉の筋肉の方が快不快とより強く比例した**（68名）[Larsen 2003]（抄録）。
- 前頭部の筋電は 20〜30 Hz で強さが最大で、弱い力でも 12 Hz 以上に混入する [Goncharova 2003]。
- 疲れるにつれて、全体で θ 波・α 波が増え、β 波も主に前頭部で大きく増えた（48名の模擬運転）[Craig 2012]（抄録）。

**比率の指標**
- 「エンゲージメント指数」（β 波 ÷（α 波＋θ 波））は、NASA の研究で、課題への取り組みの度合いを最もよく反映した [Pope 1995; Freeman 1999]（抄録）。どちらも、自分で操作する追跡課題での検証である。
- θ 波 ÷ β 波の比は、注意欠如・多動症（ADHD）の研究で頭のてっぺん（Cz）で多く使われてきた。9研究のメタ分析は、信頼できる診断の指標ではないと結論した [Arns 2013]（抄録）。
- 帯域の比の指標は、波としての成分と、波でない成分（§18）を混同するという論文がある（題名による）[Donoghue 2020b]（書誌）。

**γ 波（30 Hz 以上）**
- 筋肉の活動の周波数（約20〜300 Hz）は、高い周波数の脳の活動と完全に重なる [Muthukumaraswamy 2013]。
- 刺激の 0.2〜0.3 秒後の一時的な γ 波の増加は、小さな無意識の眼球運動（微小サッカード）で説明できる [Yuval-Greenberg 2008]（抄録）。
- 市販のヘッドバンド Muse と研究用の脳波計の γ 波の強さの一致は r = .48、基準の取り方を変えると r = .17（有意でない）[Cannard 2021a]（bioRxiv 版本文、要約経由）。
- 市販の脳波計の研究で、γ 波を筋肉の信号のために信頼できないとして解析から外した例がある [Friedman 2015]。

## 18. スペクトルの傾き（非周期成分）

脳波を周波数ごとの強さで表したもの（パワースペクトル）は、「波としてはっきり出ている成分」（α 波のピークなど）と、「周波数が高いほどなだらかに弱くなる成分」が重なってできています。後者を **非周期成分**（1/f 成分）と呼び、その傾きを指標として使う研究があります。

- 通常の帯域の強さの計算は、波の成分と非周期成分を混同しうる。例えば、傾きが変わるだけで「α 波の強さが変わった」ように見える。スペクトルを2つに分けるアルゴリズム（FOOOF、現在の名前は specparam）が提案されている [Donoghue 2020]（本文）。
- 計算モデルで、脳の興奮と抑制のバランス（E/I 比）がスペクトルの傾きから推定できることを示し、サルで全身麻酔によって傾きが急になった [Gao 2017]（抄録）。
- 4つのデータセットで、傾きは、起きているときと、麻酔・睡眠のときを区別した [Lendner 2020]（抄録）。
- 28名 × 2週間の研究で、眠ると傾きが急になるだけでなく、**起きているときも課題に取り組むと傾きが平らになった**。30〜45 Hz の範囲の傾きだけが成績と相関した [Höhn 2024]（抄録）。
- 非周期の信号はシナプスの性質で変わるが、波の成分の測定はそれほど乱さない、という報告がある [Brake 2024]（抄録）。
- スペクトルの特徴によっては、2つの成分の分離が難しくなる場合があり、使い方の推奨がまとめられている [Gerster 2022]（抄録）。
- 0〜26歳で、傾きの値が年齢とともに変わることが系統的レビューで報告されている [Stanyard 2024]（抄録、検索結果の要約）。

## 19. 左右の前頭部の α 波の差（FAA）

FAA（frontal alpha asymmetry）は、右の前頭部と左の前頭部の α 波の強さの差です。§1 の「接近・回避」の考え方と結びつけて研究されてきました。

**計算の仕方** [Smith 2017]（本文）
- 標準的な値は、ln（右の α 波の強さ）− ln（左の α 波の強さ）。ln は自然対数。例えば ln Fp2 − ln Fp1。
- α 波が強いところほど脳の活動が低いと仮定して、値が大きいほど左の前頭部の活動が相対的に大きいと読む。
- この値は左右の相対的な差だけを表し、左が弱まったのか右が強まったのかは区別できない。
- 処理の例: 1〜2秒ごとに区切り、窓関数をかけてフーリエ変換し、平均する。α 波の範囲は成人で通常 8〜13 Hz。
- 信頼できる値は約100区間（1〜3分のノイズのないデータ）から得られうる。ノイズの除去で約半分が失われることが多いので、目標の2〜3倍の長さを記録するとよいとしている。
- 204名・8回の研究で、区間数が約100になると値の一貫性が 0.90 に近づいた [Towers & Allen 2009]（抄録）。

**基準の電極の影響**
- 脳波は、ある電極と「基準の電極」の電位の差として測る。基準の取り方には、耳たぶ、耳の後ろの骨（乳様突起）、全電極の平均、頭の表面の電流の推定（CSD）などがある。
- 32チャンネルの記録を基準の取り方を変えて比べると、前頭部の左右差は基準によって大きく変わり、後頭部ではほとんど変わらなかった [Hagemann 2001]（抄録）。
- Smith 2017 は、頭のてっぺん（Cz）を基準にするのは特に問題が大きく、CSD が推奨されるが60チャンネル程度が必要で、電極が少ないと妥当性が下がると記している。迷ったら複数の基準で結果を比べるよう述べている [Smith 2017]。
- 306名を4回測った研究で、うつ病と左の前頭部の活動の低さの関係は、CSD のときだけ一貫していた [Stewart 2010]（抄録）。
- 市販のヘッドバンド Muse と研究用の脳波計の FAA の一致は、同じ種類の基準どうしで r = .67、研究用を平均の基準にすると r = .37 だった [Cannard 2021a]。
- Allen 2004 は、生の信号から前頭部の左右差の指標を得るまでの処理と、統計的・方法論的な問題をレビューしている [Allen 2004]（抄録）。Hagemann 2004 は、ノイズ・基準・CSD・状態と性格に関わる問題と解決策をレビューしている [Hagemann 2004]（抄録）。

**状態の指標か、性格の指標か**
- 59名・4回の測定で、左右差のばらつきの約60%は時間がたっても変わらない「その人の特徴」、約40%はその時々の変動だった [Hagemann 2002]（抄録）。
- F3/F4 の再現性（ICC）は 0.56〜0.68 で、集団全体では前頭部に有意な左右差はなかった [Metzen 2022]（本文）。

**大規模な検証とメタ分析**
- うつ病（1883名）と健常（2161名）を比べた16研究のメタ分析で、差の大きさ（効果量）は d = −0.007（ほぼ0）だった [van der Vinne 2017]（抄録）。それ以前のメタ分析は中程度の効果を報告していたが、記録時間などの条件の影響が大きかった [Thibodeau 2006]（抄録）。
- **740名の研究（事前に解析方法を登録し、多数の解析の分かれ道を検討）で、FAA は課題によって確実には動かず、性格とも関連しなかった。著者は、状態の指標としても性格の指標としても、接近動機づけの指標としての妥当性を支持できないと結論している** [Paul 2025]（抄録）。
- 61論文のレビューは、画像や音だけの刺激より、動画のような現実的な刺激の方が、接近・回避の FAA の効果を生みやすいとしている [Sabu 2022]（抄録）。

**音楽・映像と FAA**
- 喜び・幸福の曲で左、恐怖・悲しみの曲で右の前頭部の活動が相対的に大きかった。感情の強さは左右差ではなく前頭部全体の活動の量で区別された [Schmidt & Trainor 2001]（抄録）。
- DEAP では、「好き」の評価が高いほど左の前頭部の α 波・θ 波が強くなる（左の活動が下がる）という、古典的な予想と逆の結果が報告された [Koelstra 2012]（本文）。
- 本人が選んだ鳥肌の立つ曲で、前頭部の左右差に効果はなかった [Chabin 2020]。Fp1/Fp2 で、好きな曲に対する左右差は出なかった [Tseng 2021]。
- 市販の脳波計（Emotiv）では、クリップ単位の平均で快不快に有意な差がなかった [Friedman 2015]（本文）。市販のヘッドバンド Muse の230名の研究では、前頭部の左右差と主観的な幸福感に関連はなかった [Cannard 2021b]（抄録）。

**脳性麻痺の場合**
- 片側に麻痺のある脳性麻痺の子ども26名の脳波で、帯域ごとの左右の分布が健常児と違い、α 波の左右の脳の間のつながりが低かった [Kułak 2005]（抄録）。

## 20. 前頭部の正中線の θ 波（Fmθ）と、音楽の快の θ 波

- Fmθ（frontal midline theta、5〜7 Hz）は、前頭部の正中線（Fz 付近）に出る θ 波。71チャンネルの解析で、発生源は脳の内側の前帯状皮質付近とされ、記憶の負荷とともに増えた [Onton 2005]（抄録）。
- 内側の前頭部の θ 波は、認知の制御が必要なことを知らせる共通の仕組みを反映するという見方がある [Cavanagh 2014]（抄録）。
- Fmθ は散発的で、出る頻度が低い。特定の認知機能に結びつけるのは難しいとされる [Mitchell 2008]（抄録）。
- 快い曲で Fmθ が強くなった [Sammler 2007]。意識障害の患者21名で、好きな音楽で Fmθ が増えたのは10名（植物状態6名、最小意識状態4名）だった [O'Kelly 2013]。
- 音楽の快に関する θ 波の研究では、右の側頭部と前頭部の θ 波のタイミングのそろい方が快と関係するという報告が続いている [Ara 2020; Ara 2021; Ara 2026]（§2）。

## 21. 瞬き・額の筋肉の信号・人どうしの同期

これらは脳そのものの信号ではありませんが、額の電極で一緒に記録されるもので、状態の推定に使った研究があります。

**瞬き**
- 自然な瞬きの頻度は、脳のドーパミンの働きを間接的に表す指標とされる [Jongkees 2016]（抄録）。
- 動画を見ているときの瞬きの頻度は、興味とは相関せず、映像のカット（場面の切り替え）の数で変わった。興味を反映したのは、他の視聴者との瞬きの**タイミングのそろい方**だった [Nakano & Miyazaki 2019]（抄録）。
- 2歳児が自然に動画を見ているとき、瞬きを抑えるタイミングは、本人が感じた刺激の目立ちやすさと関与を反映した [Shultz 2011]（抄録）。
- 意識障害の患者のうち植物状態の群では、好きな音楽で瞬きの頻度が有意に増えた [O'Kelly 2013]。
- 重症心身障害者4名で、快・不快の環境音を病室のベッドで聞かせると、**全員・全回で、不快な音のときの瞬きの頻度が安静・快い音のときより高く、快い音のときは全員で安静より低かった**。重症者の瞬きの頻度は定型より低く、個人差が大きかった [橋口 2022]（抄録）。
- 市販の脳波計 MindWave による瞬きの認識の精度は50%未満だった [Maskeliunas 2016]（抄録）。

**額の筋肉の信号（高い周波数の強さ）**
- 眉の筋肉の筋電は、不快で増え、快で減る [Larsen 2003]。前頭部の筋電は 20〜30 Hz で最大 [Goncharova 2003]。

**人どうしの同期（被験者間相関、ISC）**
被験者間相関（ISC: inter-subject correlation）は、同じ動画などを見た複数の人の信号が、時間の流れの中でどれだけそろって動くかを表す指標です。
- 同じ物語を聞いた・見た人どうしで、心拍の動きが同期した。注意をそらすと同期が下がり、内容をどれだけ覚えているかを予測した。意識障害の患者では健常者より低かった [Pérez 2021]（抄録）。
- 情報動画を見ているとき、脳波・視線・瞳孔・心拍で人どうしの同期が生じ、注意の状態に合わせて一緒に変わった [Madsen & Parra 2022]（抄録）。
- 繰り返し聴いた音楽や、なじみのある様式の音楽では、脳波の人どうしの同期が下がった [Madsen 2019]（抄録）。
- ISC の計算と統計の方法を解説した論文がある [Nastase 2019]（書誌）。

# 第4部 重度障害のある方の状態・快不快の評価

この部では、言葉で気持ちを伝えることが難しい重度の障害のある方について、快・不快や覚醒の状態をどう評価してきたかをまとめます。

**用語**:
- **PIMD**（profound intellectual and multiple disabilities）: 最重度の知的障害と重い運動障害が重なっている状態を指す、海外で使われる用語。
- **重症心身障害**: 重度の肢体不自由と重度の知的障害が重なっている状態を指す、日本で使われる用語。大島分類という区分で1〜4に当たる。
- **CP（脳性麻痺）**: 発達の時期の脳の損傷による、運動や姿勢の障害。

## 23. 行動の観察

本人が自分の気持ちを報告できないので、周りの人が表情・声・体の動きを観察して判断する方法が基本になっています。

**表出の個人差と評価法**
- PIMD の方6名で、ビデオの重要場面（critical incidents）の分析と、親・支援者への質問紙を組み合わせ、個人ごとの快・不快の表出プロファイルを作った。親・支援者・研究者の判断には有意な相関があったが、それぞれが補い合う情報を持っていた。主な表出手段は発声と表情だった [Petry & Maes 2006]（抄録）。
- PIMD の方の反応は idiosyncratic（その人独自）と表現され、そのために感覚評価そのものが難しいとされる [Lima 2012]（抄録）。
- 重度・最重度知的障害の方の情動や内的状態を評価する、包括的・標準化された方法は存在しないとレビューされている [Adams & Oliver 2011]（抄録）。
- 知的・発達障害の情動的ウェルビーイング（EWB）の主観報告尺度（33論文・20尺度）のスコーピングレビュー: 多くは QOL 尺度で EWB を独立の構成概念として扱っておらず、検証対象は主に軽度〜中等度の成人だった [Mercier 2025]（抄録）。知的障害の EWB 尺度についてのレビューのレビューもある [Hall 2025]（抄録）。
- 英国では、重度のコミュニケーション困難がある方の苦痛のサインと満足時のサインを個人ごとに記録する観察ツール DisDAT が使われている [Regnard 2007]（書誌）（§30 も参照）。

**観察者の信頼性とバイアス**
- 利用者をよく知る支援者24名に、PIMD の成人4名の映像12本を見せ、好き・嫌いと判断の確信度を評価させた [Hogg 2001]（抄録）。
  - 観察者ごとのばらつきは大きかった。集団としては映像の違いを有意に区別し、判断のパターンも観察者間でよく一致した。
  - **「どの刺激を出したか」という文脈情報を与えると、4本の映像で判断がより極端になった**（「本人が好きだと思われている刺激」だと分かるとポジティブ判定がさらにポジティブになった）。
- PIMD の覚醒度（alertness）の観察研究42本のレビューでは、信頼性がほとんどの研究で中心的な問題だった [Munde 2009]（抄録）。
- 自己報告ができないため、行動観察を唯一の情報源にすることの限界が明記されている [Vos 2012]。
- 気分（MIPQ で測定）と情動の関係: 27名に支援者が選んだ陽性・陰性刺激を各4つ提示すると、気分が良いほど陽性刺激に対する情動の量・頻度が多かった。陰性刺激ではこの関係はなかった [Vos 2013]（抄録）。
- PIMD 研究の方法論上の課題は、対象者の定義、リクルート、データ収集と測定道具、解析、倫理と本人の「声」、理論モデルの6つに整理されている [Maes 2021]（抄録）。

**好みの刺激を特定する方法（preference assessment）**

好きなもの・嫌いなものを、周りの人の印象だけでなく、決まった手順で確かめる方法の研究があります。
- 最重度障害の方の強化子の特定について、職員の意見と系統的な好み評価を比べた研究がある（題名による）[Green 1988]（書誌）。
- 最重度の知的障害の方での刺激の好みと強化子の価値の評価法 [Pace 1985]（書誌）。
- PIMD の方5名で、行動として操作的に定義した「幸福指標（happiness indices）」が、最も好む刺激で増え、最も好まない刺激で不幸指標が増えることで妥当性を示し、実践者の評定とも一致した [Green & Reid 1996]（抄録）。
- 重度・最重度の知的・重複障害の幸福指標を高める研究（1990–2004年、24研究）の総説 [Lancioni 2005]（抄録）、重度〜最重度の発達障害の選択・好み評価の研究（1996–2002年、30研究）の総説がある [Cannella 2005]（抄録）。

## 24. 心拍などの生理指標

心拍、呼吸、皮膚の電気の流れやすさ（汗の量を反映。皮膚コンダクタンス）、皮膚温などの体の信号を「生理指標」と呼びます。言葉や行動に表れにくい反応をとらえる方法として研究されてきました。

- **心拍変動（HRV）**: 心拍の間隔のゆらぎ。高い周波数の成分（HF）は副交感神経（落ち着き）、LF/HF の比は交感神経（興奮）の指標として使われることがある。
- **RSA**: 呼吸に伴う心拍のゆらぎ。

## 25. 脳の指標

脳波のほか、脳の血流の変化を近赤外光で測る NIRS（酸素と結びついたヘモグロビン oxy-Hb の量を測る）や、刺激に対する脳波の反応（事象関連電位、ERP）を使った研究があります。

**意識障害の方での「好きな音楽」**

意識障害（DOC）には、目は開くが周りに反応しない植物状態（VS、無反応覚醒症候群 UWS とも呼ぶ）と、わずかに反応がある最小意識状態（MCS）がある。
- 健常20名と VS/MCS 21名に、生演奏の好きな音楽、呼吸に同期した即興音楽、嫌いな音楽の録音、ホワイトノイズ、無音を提示し、EEG・HRV・呼吸・行動を記録した [O'Kelly 2013]（抄録）。
  - 健常者では、好きな音楽で呼吸数が増え、EEG パワーが全帯域で増えた（p = 0.05–0.0001）。
  - 患者群の反応は不均一で、好きな音楽で前頭正中θの振幅が増えたのは VS 6名・MCS 4名、前頭 α が増えたのは VS 3名・MCS 4名だった。VS 群では瞬目率が有意に増えた（p = 0.029）。
- DOC 患者13名で、本人の好きな音楽の抜粋の後と、連続音（対照）の後に、自分の名前への ERP を記録すると、名前への脳反応は音楽条件の方が多くの患者で観察された。音楽条件で弁別反応があるかどうかは予後と関連しているようにみえた [Castro 2015]（抄録）。
- DOC 5名の fMRI: 好きな音楽の聴取中、聴覚ネットワークと左背外側前頭前野・左中心前回の機能的結合が強まった [Heine 2015]（抄録）。
- DOC 32名（VS/UWS 17、MCS 15）と健常16名で、前頭–頭頂ネットワークの頭皮 EEG（θ–γ の位相振幅結合など）を、本人の好みの音楽・リラックス音楽・安静で比べた。健常者は好みの音楽で θ–γ 結合が強かった。VS/UWS では3条件に差がなかった。3か月後に改善した MCS 患者は、好みの音楽への反応が明瞭だった [Xiao 2024]（抄録）。
- DOC への音楽刺激のスコーピングレビュー（2010–2021年、34論文）: 録音・対話的・反応随伴の3類型とも結果はおおむね肯定的だが、方法論上の問題が多く結論は出せないとしている [Lancioni 2021]（抄録）。DOC への音楽介入の系統的レビュー（22研究・329名）は、方法論の質と結果が不均一と報告している [Grimm & Kreutz 2018]（抄録）。

**脳性麻痺での情動 ERP と痛み**
- CP 児15名と定型発達児に快・不快・中立の画像を見せると、CP 児では後頭部の早期 ERP（P100、N200）の振幅が小さく、主観的にも情動画像の覚醒度を低く評定した [Belmonte 2019]（抄録）。
- CP 成人18名と対照15名: CP 成人は痛覚感受性が高く、情動理解の困難が大きく、情動画像への ERP 振幅が小さかった [Riquelme 2025]（抄録）。
- CP 成人20名と対照20名: CP 群は痛みを伴うストレッチで、安静時より前頭・体性感覚野の θ・α・β パワー密度が高かった。対照群では逆に痛くないストレッチで高くなった。痛覚感受性が高い CP 者ほど α パワー密度が大きかった [Sabater-Gárriz 2024]（抄録）。

**重症心身障害者の脳波（国内）**
- 重症心身障害者6名と健常者11名に、自分の名前と単語を聞かせた。健常者では θ パワーが増えたが、患者では同じパターンは出なかった。θ の位相同期は6名中4名で、自分の名前に特異的に増えた [Tamura 2015]（抄録）。
- 重症心身障害児5名で、好きな玩具の呈示の前の予告（声かけのみ vs 声かけ＋身体接触）を比べると、3例では複合予告で脳波基礎律動の事象関連性変動が顕著になり、2例では逆に減少・消失した [鈴木 2017]（抄録、紀要）。
- 重症心身障害者9名（19–39歳）と健常9名に、高揚曲（ヘンデル）と鎮静曲（アルビノーニ）を姿勢保持装置上の座位で聴かせ、ヘッドセット型脳波計（TOKAI Ord TO-101）、心電図、唾液アミラーゼ、フェイススケールで評価した。曲は本人の好みで選んだものではない。群間差（心拍、CVRR、α・β・θ）はあったが、曲調の違いによる差は重症者・健常者とも有意でなかった。重症者では安静に比べ両曲で心拍増加・CVRR 低下の傾向、鎮静曲で後頭部 α の増加傾向があった [菊次・後藤 2026]（学会抄録）。

**NIRS（国内）**
- 観察で視覚刺激への注視が確認された重症児者と健常成人では oxy-Hb が増え、注視しなかった重症児者ではほとんど変化しなかった [中村 2009]（抄録）。
- 重症心身障害児者の応答は「力動感を伴うわずかな印象」であることが多く、療育者は応答に確信が持てないことがある。NIRS は日常の療育場面で測れ、脳血流の情報と観察を合わせることで根拠のある療育方法を選べる可能性があるとする総説 [谷口・平野 2013]（抄録）。
- 表情表出のない12歳（大島分類1）で、テンポの速い曲で脳血流が増え、静かな曲（ノクターン）では広い範囲で減少が続いた。表情・運動・眼球運動に明らかな変化はなかった [安西・井合 2013]（学会抄録）。
- Rett 症候群の成人女性1名（大島分類2）で、日中よく見ている幼児番組の視聴中、画面中の人物・キャラクターへの注視が増え、前頭部の oxy-Hb が増加した（アイトラッカー＋前頭部 NIRS）[平野 2013]（学会抄録）。

**脳性麻痺と好みの音楽・脳波の計画（結果未公表）**
- CP の成人・小児（予定36〜40名、2–65歳）で、日常の快・不快活動（介護者と選定）と、本人の好みの音楽あり・なしでの運動（AB デザイン）について、OpenBCI 16ch EEG（Fp1・Fp2 を含む）、心電図、皮膚電気活動、皮膚温、慣性センサー4個、気分尺度を測るプロトコルが公表されている。**認知能力がきわめて限られる人は除外**されている。2026年10月時点で結果論文は見つかっていない [Gómez-González 2024]（本文、要約経由）。

**音楽療法中の脳間同期**
- 発話のない重度の身体障害児と親の音楽療法中の脳波で、神経生理学的な同期を調べた研究がある [Samadani 2021]（抄録）。
- 発話のない CP の青年1名（18歳）、親、音楽療法士の3者の EEG を同時計測すると、青年–親のペアだけ、音楽で脳間同期が高かった（前頭・側頭の低周波）[Kang 2022]（抄録）。

**探索の範囲について**
- この調査の検索（PubMed、CiNii、J-STAGE ほか）では、「CP／PIMD・本人の好みの動画や音楽・前頭部の脳波・査読論文」の4条件をすべて満たす研究は見つからなかった。PIMD を対象に生理・神経生理指標で情動を評価した系統的レビュー（2020〜2026年）も見つからなかった。系統的レビューではないので、検索範囲の外にある可能性は残る。

## 27. 脳性麻痺（CP）の方の脳波の特徴と、計測のときの課題

脳性麻痺の方の脳波には、病気や薬の影響で、健常の方とは違う特徴が出ることがあります。

**てんかんの合併と脳波の異常**

| 項目 | 値 | 出典 |
|---|---|---|
| てんかんの合併（CP 児、欧州17登録、9654名、1976–1998年出生） | 35%（3424名）。そのうち72%が登録時に服薬中。ジスキネティック型・両側痙直型で多い | [Sellier 2012]（抄録） |
| てんかんの合併（CP 児、系統的レビュー・メタ分析、30研究） | 4人に1人。ほかに、4人に3人が痛み、2人に1人が知的障害、4人に1人が話せない、5人に1人が流涎 | [Novak 2012]（抄録） |
| てんかんの合併（CP 74名、トルコ） | 四肢麻痺型で60.5% | [Senbil 2002]（抄録） |
| てんかんの合併（重症心身障害児者施設の入所者、6施設） | 66.8%。そのうち37.3%が難治てんかんの基準を満たす | [小西 2010]（抄録） |
| EEG 異常（てんかんのない CP） | 39.5%（てんかんのある CP では90.3%） | [Senbil 2002] |
| EEG 異常（発作のない CP 児、70名） | 76%（抄録には「発作のない群で正常24名」とも書かれており、抄録内の数値に不整合がある）。発作のある群（81名）では92.6% | [Al-Sulaiman 2001]（抄録） |

- 片麻痺型 CP 児26名の定量 EEG で、帯域ごとの左右の半球分布が健常児と異なり、α 帯の半球間コヒーレンスが低かった [Kułak 2005]（抄録）。

**薬剤の影響**
- 薬剤による EEG 変化で最も多いのは β 活動の過剰と軽度の θ 増加で、びまん性の δ、三相波、burst suppression などが出ることもある [Blume 2006]（抄録）。
- 抗痙縮薬バクロフェンを増量した CP 児1例で、全般性の鋭波バーストが出現した症例報告がある [De Rinaldis 2010]（抄録）。

**計測のときの課題**
- 重度の CP の子どもでの BCI による認知評価の課題 [Huggins 2022]（本文、要約経由）:
  - 頭部の非対称（40%超）や小頭症（30〜60%）でヘッドギアが合わないことがある。
  - 車椅子のヘッドレストとの接触でアーチファクトが生じる。発声・不随意運動もアーチファクトの原因になる。
- 市販 BCI を CP の方が使った研究では、体調・疲労・意欲によって日ごとに成績がばらついた [Taherian 2017]（抄録）。
- 発達障害児（19歳未満）でワイヤレス EEG を使った64研究のスコーピングレビュー [Park 2026]（抄録）: 85.9% が有線 EEG との妥当性検証を報告せず、79.7% がインピーダンスの閾値を明記せず、12.5% がアーチファクト処理を記載していなかった。
- 神経発達症の研究でモバイル EEG を使う機会と課題を論じたレビュー [Lau-Zhu 2019]（付録A）。

# 第5部 脳波以外の信号（概要）

## 28. 心拍・皮膚の電気活動・表情・視線など

脳波以外の信号で、状態の推定に関係する報告を簡単にまとめます。

**心拍・心拍変動（HRV）**
- PIMD の方では、陰性刺激の提示後6秒の心拍が陽性刺激より低かった [Vos 2012]。心拍の上昇は苦痛でも喜びでも生じた [Kildal 2021]。
- 重症心身障害児者では、交感神経の亢進が不快でも楽しい場面でも生じた [北川 2011]。
- 同じ物語の視聴・聴取で心拍が人どうしで同期し（ISC-HR）、注意で変わり、意識障害の患者では低かった [Pérez 2021]（§21）。
- 音楽の快の連続評定は、心拍を含む交感神経系の覚醒指標と強く正に相関した [Salimpoor 2009]。
- ストレスの推定（ストレス研究の公開データセット SWELL・WESAD）では、本人専用モデル 95%超に対し、汎用モデル 42.5%。本人のデータ100標本で 95.2% [Nkurikiyeyezu 2020]（§11.2）。
- 施設での自然な記録で、PIMD の方2名の脈波由来の HRV から pleasure/displeasure/neutral を推定すると精度 0.62（多数派 0.52）[Slapničar 2020]。カメラ由来の rPPG でテストできたのは12区間だけだった。

**皮膚電気活動（EDA）・皮膚温**
- PIMD の方で、陽性情動時に皮膚コンダクタンスが上がった [Vos 2010]。皮膚コンダクタンスは楽しい刺激で最大、怒りの刺激でも高かった [Krämer & Zentel 2020]。低強度の陰性表出で皮膚温が高かった [Vos 2012]。
- 好物の呈示中の鼻尖温度は全員で上昇傾向だったが有意差なし [桃川 2017]。

**表情**
- 四国大学の NICT 委託研究（重症児者）は、「一般人の表情データを学習させた感情モデルは使用できないことがわかった」「表情解析により重症児の快・不快の検証が一部可能であることがわかった」と報告している（§30）。
- 認知症の方の痛みを顔画像（顔面アクションユニット）と臨床情報から評価するアプリがある（PainChek、§30）。
- 介護施設で、カメラ映像の表情と音声から7感情を分類し、入居者アンケートとの一致が約75%だったという実証の発表がある（日立×NTTBP、§30）。
- 快刺激では大頬骨筋、不快刺激では皺眉筋の筋電が変化する [Larsen 2003]。

**視線・瞬目**
- 瞬目の同期は動画への興味を反映した [Nakano & Miyazaki 2019]。瞬目を抑制するタイミングは関与を反映した [Shultz 2011]。
- 重症心身障害者で、瞬目率が快・不快の環境音を区別した [橋口 2022]。
- 視線入力でコミュニケーションを練習するツール（EyeMoT）が、全国の支援学校のほぼすべてで導入されていると記されている（§30）。

**複数の信号の組み合わせ（マルチモーダル）**
- 自閉症児35名で、顔・身体・音声・自律神経の信号から、個人化モデルで valence・arousal・engagement を推定した [Rudovic 2018]（§11.4）。
- 重症心身障害の男児1名で、心電図の R-R 間隔・視線・筋電などから negative / not negative を推定した [Tanabe 2023]（§11.4）。

- AMED 障害者対策総合研究開発事業の令和6〜8年度の採択課題一覧を検索した範囲では、重症心身障害児者の感情・意思を推定する課題は見当たらなかった（一覧の全件精査はしていない。https://www.amed.go.jp/koubo/14/03/1403C_00088.html ほか）。

# 第7部 倫理

## 32. 同意できない方が研究に参加するときの決まり

本人が研究への参加に同意できない場合について、国際的な宣言・指針と国内の指針が定めていることをまとめます。

**ヘルシンキ宣言（2024年10月改訂）** [WMA 2024]（公式ページで該当箇所の原文を確認）
- 同意能力のない方は、本人に利益が見込まれる研究か、**最小リスク・最小負担**の研究にだけ参加させる（第28項）。
- 本人が賛意（assent）を示せる場合は、法定代理人の同意に加えて賛意を求める。本人の不同意（dissent）は尊重されるべき（第29項）。
- 脆弱な立場にある方を研究に含めるのは、その方の健康上のニーズと優先事項に応える研究で、かつ、より脆弱でない集団では実施できない場合、または除外すると格差が広がる場合に限る（第20項）。
- 条番号は調査時に確認したもの。

**CIOMS 2016 指針16（同意能力のない成人）** [CIOMS 2016]（本文。公式サイトに接続できず、大学がミラーした PDF で確認）
- 同意能力のない成人は、科学的な理由がない限り研究に含めるべきとしている。
- 法定代理人の許可（本人の以前の選好・価値観を考慮）と、能力に応じた本人のアセントが必要。
- 本人の参加拒否は原則として尊重する。
- 本人に利益のない手続きには、(a) 同意できる人で先に検討する（同意できない人でしか得られないデータを除く）、(b) リスクを最小リスク以下に抑える、という2つの条件を課している。

**国内指針（人を対象とする生命科学・医学系研究に関する倫理指針）** [生命・医学系指針 2023]（本文）
- 第9の1（代諾）: 研究計画書に「代諾者等の選定方針」と「説明事項（当該者を研究対象者とすることが必要な理由を含む）」を書く。対象者は「成年であって、インフォームド・コンセントを与える能力を欠くと客観的に判断される者」。
- 第9の2（インフォームド・アセント）: 対象者が自らの意向を表せると判断されるときは、アセントを得るよう努める。アセントの説明事項と説明方法を研究計画書に書く。拒否の意向は尊重するよう努める（本人に直接の健康上の利益が期待され、代諾者が同意するときを除く）。
- ガイダンス（2024-04-01 改訂）の記載 [生命・医学系ガイダンス 2024]（本文）:
  - 代諾者は、配偶者・父母・兄弟姉妹・子・孫・祖父母・同居の親族などから選ぶのが基本だが、画一的にではなく、本人の意思と利益を代弁できる人を選ぶ。
  - 成年後見人が選任されていることだけで同意能力なしと判断しない。後見人などが付いた方は「社会的に弱い立場にある者」として特別な配慮が要る。
  - アセントの対象は「言語理解が可能で、理性的な思考に基づき自らの意思を表することができる状態」。対象外でも、理解できる事項は説明することが望ましい。
- 2026年改正（2026-08-27 告示、2026-12-01 施行）[生命・医学系指針 2026改正]（本文）: 基本方針に患者・市民参画を追加。インフォームド・コンセントの手続きをリスク別の3区分に再編。倫理審査の形態をリスクに応じて整理。第9の代諾・アセントの条文は実質的に同じ。実施中の研究は経過措置で従前の例によることができる。改正ガイダンスは「後日掲載」（2026-10-12 時点）。

**PIMD 研究の倫理に関する文献**
- 同意能力のない方の「声」を研究にどう反映させるかが、方法論上・倫理上の中心的な課題とされている [Maes 2021; Mietola 2017]（抄録）。

# 付録A 民生用・ウェアラブル脳波の検証状況

研究用の脳波計ではなく、一般向けに売られている脳波計（民生用）や身に着ける形の脳波計（ウェアラブル）が、どこまで研究用の機器と同じように測れるかを調べた研究をまとめます。

- 民生用 EEG を使った査読付き研究のスコーピングレビューは916件（雑誌論文531、会議論文385）を同定した。使用頻度は Emotiv、NeuroSky MindWave、OpenBCI、interaXon Muse、MyndPlay Mindband の順。用途は BCI が最も多く、次いで実験研究、信号処理、検証、臨床の順だった [Sabio 2024]（本文）。
- 同レビューの記載 [Sabio 2024]:
  - 研究用 EEG は通常数十個の電極を生理食塩水ゲルなどで装着するが、民生用は電極が少なく、導電媒体をほとんどまたは全く使わない。
  - 民生用 EEG は研究用より信号対雑音比がかなり低い。
  - Emotiv と OpenBCI の機能的結合は研究用より劣る。Emotiv は頭部に正確に合わないと信号の信頼性が低く、EPOC+ の信号品質は内蔵電池の使用に伴って経時的に下がった。
  - NeuroSky MindWave と研究用システムの信号品質の差は非常に小さく、閉眼条件で良好な再検査信頼性が報告され、開眼条件ではやや低かった。
  - MyndPlay Mindband と Muse の検証研究は見いだせなかった（一方で Muse を使った ERP の検証研究として Krigolson 2017 がある）。
- 単一チャンネル乾式センサの携帯機器と研究用システムの同時記録（成人20名）では、周波数スペクトルの相関は F3 部位で最も高かった（機器内処理 r = .90、標準処理 r = .89）[Johnstone 2012]（抄録）。
- 医療用2機種と民生用2機種（Muse、Mindwave）を Fp1 で比べた研究（5名）では、B-Alert・Enobio・Mindwave の Fp1 パワースペクトルは類似し、Muse は広帯域でパワーが高く、再検査の変動が最大だった。同研究は、医療用システムがデータ品質・信頼性・解析の深さで明確な利点をもつと結論している [Ratti 2017]（抄録）。
- 民生用ヘッドバンド3機種と研究用 EEG（Brain Products）を比べた研究（19名）[Mikhaylov 2024]（本文の一部）:
  - Muse（AF7/AF8、FPz 参照）は最も一致度が低かった。
  - 前頭部では、Muse・研究用のどちらでも、開閉眼による α 抑制（Berger 効果）が有意でなかった。Muse と研究用の前頭 α パワーは有意に相関しなかった。
  - 乾式電極はどの機種も低周波のパワーが高かった。
- Muse と研究用 64ch（BioSemi）の比較（40名、閉眼安静、約30分ずらした別記録）[Cannard 2021a]（bioRxiv 版本文、要約経由）:
  - 研究用（乳様突起参照）との相関: α パワー r = .87、β r = .84、θ r = .73、δ r = .59、γ r = .48。個人 α 周波数 r = .91。
  - FAA は r = .67（乳様突起参照どうし）。研究用を平均参照にすると r = .37。γ は平均参照との比較で r = .17（有意でない）。
- NeuroSky MindWave と医療用の携帯 EEG を Fp1 で同時記録した研究（21名、12分安静＋60分の運転シミュレーション）では、両者の信号は有意に相関したが、MindWave は雑音が多く信頼性が低く、低周波でスペクトルの差・較正誤差の可能性があった [Rieiro 2019]（抄録）。
- 無線 EEG 48機種の特徴一覧と、無線 EEG を使った高インパクト論文110本の分類が報告されている。メーカーの情報提供がときに不透明であると記されている [Niso 2023]（抄録）。
- 新しい電極技術の性能検証に関する標準がないことが、ウェアラブル EEG 普及の主なボトルネックとみなされている [Casson 2019]。
- 移動しながらの記録では、非定型な動きに起因するアーチファクトの除去が重要とされる。移動型 EEG の信号品質は（少なくとも一部のシステムで）有望だが、体系的な研究と追加の検証が必要とされている [Lau-Zhu 2019]（本文）。
- 3機種の無線 EEG と有線 BioSemi の比較では、頭部サイズへの適応性、快適性、電極位置のばらつき、電極–頭皮接続の安定性、外部イベントとの時間同期が評価項目とされた [Hairston 2014]（抄録）。
- ear-EEG の総説（123論文）では、スペクトル解析は頭皮 EEG と同程度の結果が得られるとされている [Kaongoen 2023]（抄録）。

# 付録B 用語集

本文に出てくる用語の意味です。出典が付いているものはその文献の定義、付いていないものは分野で一般的に使われる意味です。

**脳波と信号**

| 用語 | 意味 |
|---|---|
| 脳波（EEG） | 頭の表面に置いた電極で記録する脳の電気活動 [Kane 2017]。脳の表面（大脳皮質）の多数の神経細胞の活動が重なったもの |
| 電極 | 頭や体に付けて電気信号を拾う部品。ゲルを使う湿式と、使わない乾式がある |
| チャンネル | 記録する信号の系統の数。電極1個（とその基準）で1チャンネル |
| 基準の電極（リファレンス） | 他の電極の電位を測るときの基準にする電極。耳たぶや耳の後ろの骨（乳様突起）に置くことが多い |
| 10-20法 | 電極の位置を決める国際的な配置法。額は Fp、前頭部の正中線は Fz [Acharya 2016a] |
| Fp1 / Fp2 / Fpz | 額の左・右・真ん中の電極の位置 [Acharya 2016a; Rojas 2018] |
| 周波数（Hz） | 1秒間に波が何回くり返すか |
| δ・θ・α・β・γ 波 | 周波数の範囲ごとの脳波の呼び名（§6.1 の表） |
| 帯域の強さ（帯域パワー） | 特定の周波数の範囲の波がどれだけ強く含まれているか |
| パワースペクトル | 脳波を、周波数ごとの強さとして表したもの |
| 非周期成分（1/f 成分） | パワースペクトルのうち、周波数が高いほどなだらかに弱くなる成分 [Donoghue 2020] |
| IAF（個人 α 周波数） | その人の α 波の周波数。ピーク周波数（PAF）や重心周波数（CoG）で求める [Klimesch 1999; Corcoran 2018] |
| FAA（前頭部の α 波の左右差） | ln（右の α 波の強さ）− ln（左の α 波の強さ）[Smith 2017] |
| Fmθ（前頭部の正中線の θ 波） | Fz 付近に出る θ 波 [Onton 2005] |
| アーチファクト | 脳以外に由来する信号や、機器・動きによるノイズ |
| 筋電（EMG） | 筋肉が出す電気信号。頭の表面では額・こめかみ・顎の筋肉の信号が入りやすい |
| 眼電（EOG） | 眼球の動きや瞬きによる電気信号。額の電極に入りやすい |
| 事象関連電位（ERP） | 刺激などの出来事に合わせて現れる脳波の反応。何回分も平均して取り出す |
| NIRS（近赤外分光法） | 近赤外の光で脳の血流の変化（oxy-Hb など）を測る方法 |
| fMRI・PET | 脳の血流や代謝を画像で測る方法。脳の奥の活動も測れる |
| インピーダンス | 電極と皮膚の間の電気の通りにくさ。高いとノイズが増えやすい |
| 機能的結合・コヒーレンス | 離れた部位の信号が、どれだけそろって動くかを表す指標 |
| 位相同期・位相振幅結合 | 波のタイミングのそろい方 / ある周波数の波のタイミングと、別の周波数の波の強さの結びつき |

**感情と評価**

| 用語 | 意味 |
|---|---|
| valence（バレンス、感情価） | 快か不快かの度合い [Russell 1980] |
| arousal（覚醒度） | 興奮しているか落ち着いているかの度合い [Russell 1980] |
| 接近動機づけ | 対象に近づきたいという気持ち。FAA はこれを反映するという説がある [Harmon-Jones 2010] |
| SAM | 表情の絵を並べた、感情の自己評価の尺度 |
| ラベル（正解） | 推定のモデルを学習・評価するときの「正しい答え」。本人の評価や刺激の種類で決める |
| 特徴量 | 脳波から計算した、推定に使う数値（例: α 波の強さ） |
| DE（differential entropy） | SEED 系の研究で標準的に使われる特徴量。一定の仮定のもとで帯域の強さの対数と同じになる [Zheng & Lu 2015] |
| 機械学習 | データから規則を自動で学ぶ方法。SVM、k 近傍法、決定木、ランダムフォレストなどがある |
| 深層学習 | 多層のニューラルネットによる機械学習。CNN、LSTM、Transformer などがある |
| 学習データ / テストデータ | モデルを作るのに使うデータ / 作ったモデルを試すのに使うデータ |
| 交差検証 | データをいくつかに分け、順番にテスト用に回して平均をとる評価の方法 |
| LOSO | 1人を除いて学習し、その1人でテストすることを全員分くり返す評価（leave-one-subject-out） |
| 漏洩（リーク） | テスト用のデータの情報が学習に紛れ込むこと [Li R 2021; Khan 2025] |
| チャンス | でたらめに答えたときに当たる割合（選択肢の数の逆数）。論文によっては、データの数を考慮した上限（チャンスの上限）を示している |
| いつも多い方を答える基準（多数派ベースライン） | いつも最も多い答えを返したときの正解率 |
| 正解率 / F1 | 当たった割合 / 正解の偏りに強い指標（適合率と再現率の調和平均） |
| AUC | 判別の良さの指標。0.5 がチャンス、1 が完全な判別 |
| 有意・p 値 | 統計の検定で「偶然では起こりにくい差」と判断されたこと。p 値が小さいほど偶然では起こりにくい |
| 査読 / プレプリント | 専門家の審査を経て雑誌に載ること / 査読の前に公開された論文 |
| メタ分析 / 系統的レビュー / 総説 | 複数の研究の結果を統計的にまとめる方法 / 決まった手順で文献を集めて整理したもの / ある分野の研究をまとめた論文 |
| ICC | 測定の再現性や、評価者どうしの一致の指標。1に近いほど一致する |
| κ（カッパ） | 偶然の一致を除いた、評価者どうしの一致の指標 |
| ドメイン適応・転移学習 | 学習したモデルを、性質の違う新しいデータ（新しい人・別の日）に合わせ込む方法 |
| キャリブレーション | 新しい利用者の少量のデータで、モデルを調整すること |
| 基盤モデル | 大量のデータで事前に学習し、いろいろな課題に転用する大規模なモデル |
| linear probing | 基盤モデルを固定し、最後の分類の部分だけを学習する評価の方法 |
| 被験者間相関（ISC） | 同じ刺激を受けた人どうしの信号が、時間の流れの中でどれだけそろって動くか [Nastase 2019] |
