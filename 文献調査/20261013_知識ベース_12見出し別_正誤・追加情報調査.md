## 1. はじめに

### 判定

**概ね妥当。ただし、基礎用語に3点の修正が必要で、想定サービスの使用目的を先に限定する情報を追加すべき。**

### 正誤確認

| 原文の内容 | 判定 | 確認結果と修正案 |
|---|---|---|
| EEGは頭皮電極で記録する脳の電気活動 | 要修正 | 大筋では正しいが、頭皮EEGは多数の神経活動が体積伝導した**電位差**に、眼電、筋電、動き、電極由来の信号が加わったもの。各電極直下の脳活動を局所的に直接読んでいる、とは説明しない方がよい。 |
| 「電極1個とその基準で1チャンネル」 | 要修正 | チャンネルは通常、2点間の電位差または再参照後の信号系列を指す。装置によって共通参照、双極導出、参照電極、接地電極の構成が異なり、電極数とチャンネル数は常に一対一ではない。 |
| p値が小さいほど「偶然では起こりにくい」 | 要修正 | p値は「帰無仮説と統計モデルを仮定したとき、観測値以上に極端なデータが得られる確率」。仮説が正しい確率でも、結果が偶然である確率でもない。効果量、信頼区間、多重比較、事前仮説を併記すべきである。ASA声明もこの誤解を明確に否定している（[Wasserstein & Lazar, 2016](https://doi.org/10.1080/00031305.2016.1154108)）。 |
| PIMDと重症心身障害を対応づける | 要補足 | 実務上の説明として有用だが、国・制度・研究ごとに包含範囲が異なり、同義語ではない。PIMD研究では対象の機能、感覚障害、運動、てんかん、コミュニケーション手段を操作的に記述する必要がある（[Nakken & Vlaskamp, 2007](https://doi.org/10.1111/j.1741-1130.2007.00104.x)）。 |
| BCIは脳信号で操作または状態を読み取る仕組み | 妥当 | 広義には妥当。感情・負荷推定は、意思による操作を主目的としない **passive BCI** に位置づけられることも明示するとよい。 |

### 追加すべき重要情報

1. 想定サービスの出力を、少なくとも次の別概念に分けるべきである。
   - 快／不快（valence）
   - 覚醒度（arousal）
   - 痛み・苦痛（pain/distress）
   - 注意・反応性（attention/responsiveness）
   - 眠気・覚醒水準
   - 発作・体調変化

   これらは同じではなく、1つの「状態スコア」に統合すると誤った解釈を招く。

2. 使用目的を「本人の感情を確定する装置」ではなく、「支援者が本人の状態を再確認するための補助的変化検出」に限定して記述するのが、現時点のエビデンスに合う。

3. 冒頭に次の注意書きを追加するとよい。

   > EEGで統計的な違いを検出できること、個人内で状態変化を分類できること、初対面の利用者の感情を日常環境で正しく推定できること、臨床・ケア判断に有用であることは、それぞれ別の検証課題である。

## 2. 総括

### 判定

**中心結論は妥当。最新レビューと、結論の適用範囲を追加すべき。**

### 正誤確認

- 「評価の分け方によって精度が大きく変わる」は強く支持される。データ分割だけで性能が大幅に変化し、対象者データが学習に含まれない厳密な対象者独立評価は難しい（[Moreno-Alcayde et al., 2024](https://doi.org/10.1007/s13534-023-00316-5)）。
- 対象者間・日間の非定常性とデータセットシフトが汎化の主要課題である、という記述も妥当である。449報を検索し79報を採択した系統的レビューも同じ結論である（[Apicella et al., 2024](https://doi.org/10.1016/j.neucom.2024.128354)）。
- 「前額部では眼・筋肉の混入が大きい」は妥当。弱い前頭筋・側頭筋収縮でもβ帯域を含む8–12 Hz以上に影響し得る（[Goncharova et al., 2003](https://doi.org/10.1016/S1388-2457%2803%2900169-2)）。20 Hz超では筋電の寄与が非常に大きいことも示されている（[Whitham et al., 2007](https://doi.org/10.1016/j.clinph.2007.04.027)）。
- 「重症心身障害のある人を対象に、額の少数チャンネルEEGだけで快・不快を実用的に推定できる直接証拠は不足」は妥当。ただし「研究がない」ではなく、**関連する心理生理研究はあるが、対象・信号・目的が異質で、臨床的精度を確立していない**と書くべきである。

### 追加すべき重要情報

- 2026年の系統的レビューは、重度・最重度知的障害者に対する心理生理研究5,495件を検索し34研究を採択した。眼球運動、ウェアラブル、生体温度、EEGなどが注意、社会情動的関与、情動反応に使われていたが、信頼性と包摂的な方法の改善が必要と結論した（[Vandesande et al., 2026](https://doi.org/10.1111/jar.70222)）。これは総括に最優先で追加すべき文献である。
- 2026年のDEAP／DREAMER再解析では、ランダムなepoch混在評価のROC-AUCがDEAPでvalence 0.689、arousal 0.711だった一方、対象者独立評価では0.493、0.447だった。特徴量は感情より個人を強く識別していた（[Pandilova et al., 2026](https://doi.org/10.3390/s26175327)）。「高精度」の見かけが個人識別を反映し得ることを総括に入れるべきである。
- 結論は「推定不能」ではない。妥当な言い方は、**集団一般モデルの臨床的妥当性は未確立だが、個人内の反復測定と複数情報を用いた変化検出は研究価値がある**、である。

## 3. 第1部 感情と脳の基本

### 判定

**概ね正確。感情理論の複数性と、脳部位の説明の慎重化が必要。**

### 正誤確認

| 論点 | 判定 | 確認結果 |
|---|---|---|
| valence–arousalの次元モデル | 妥当 | 感情を連続的な次元で表す代表的方法。ただし唯一の正解ではなく、離散感情、評価理論、構成主義的理論などが併存する。 |
| 接近／回避と左右前頭活動 | 要補足 | 有力な仮説ではあるが、後述のFAAを普遍的・安定的な指標とみなす証拠は弱い。理論と測定指標を分けて書くべき。 |
| 感情は単一の脳部位に宿らない | 妥当 | 現代的な総説と整合する。感情表象は知覚、注意、学習、記憶など複数水準に分布する（[Todd et al., 2020](https://doi.org/10.1146/annurev-psych-010419-051044)）。 |
| 「特定の感情に特異的な脳領域はない」 | 要修正 | 一対一の単純局在を否定する趣旨なら妥当だが、「専門化や再現性のある回路が一切ない」と読める表現は強すぎる。恐怖、防御、報酬などには複数の部分回路が関与する。 |
| 音楽快と報酬系 | 妥当 | 音楽の期待、予測誤差、報酬、運動、情動が相互作用するという現在の総説と整合する（[Vuust et al., 2022](https://doi.org/10.1038/s41583-022-00578-5)）。 |
| likingとwantingの区別 | 妥当 | 報酬研究の重要な区別。ただし人の主観的快は文脈、学習、文化、予測によって変わり、単一生理指標から直接は決まらない。 |

### 追加すべき重要情報

1. **刺激ラベルと本人の感情は別**である。「楽しい動画」「不快画像」という研究者側の分類を、その参加者が実際に感じた感情の正解として扱うとラベル誤差が生じる。本人報告、刺激カテゴリ、第三者評定、生理反応のどれを正解としたかを区別する必要がある。
2. valenceとarousalはしばしば相関し、痛み、驚き、注意、努力、運動でもarousalが上がる。したがって「覚醒度上昇＝喜び」ではない。
3. 音楽については、好み、親密性、予測、記憶、自伝的関連、聴覚特性が反応を左右する。標準刺激だけでなく、本人選択刺激と対照刺激を組み合わせる必要がある。
4. 重度障害のある人への応用では、「感情カテゴリを当てる」より、本人内での**基準状態からの変化**、刺激への反応性、繰り返し再現する選好を測る方が、理論的にも実装上も堅実である。

## 4. 第2部 脳波で感情を推定する研究

### 判定

**研究動向の把握は良好。ただし、精度の比較可能性、査読前研究の重み、基盤モデルの到達点をさらに厳密にする必要がある。**

### 正誤確認

- DEAP、SEED、DREAMER等の概要は概ね正しい。ただし、データセットごとに刺激、自己評定尺度、閾値、参加者数、セッション数、電極、前処理が異なるため、表に並べた正解率の大小を手法の優劣と解釈してはいけない。
- 「同じ人の窓が学習とテストに混ざると性能が上がる」は妥当。特に重なる時間窓、同一trial、同一session、同一participantの共有を別々に管理する必要がある。
- 101本のDEAP研究の87%に問題があったとするKhan 2025は査読前プレプリントであり、問題提起としては有用だが、総括の主根拠にはしない方がよい。査読誌の根拠として、データ分割の影響を調べたMoreno-Alcayde 2024と、個人識別交絡を定量化したPandilova 2026を前に置くべきである。
- 「チャンス＝クラス数の逆数」は、クラスが均衡し損失が単純なaccuracyの場合の便宜的基準にすぎない。不均衡なら多数派accuracy、balanced accuracy、macro-F1、ROC-AUC／PR-AUC、置換検定による経験的チャンスを用いるべきである。
- 基盤モデルは有望だが、現在の成果を前額1–2チャンネルの快・不快推定へ直接外挿できない。査読済み総説では、最大14,987人・27,062時間規模の事前学習が報告され、特に発作検出で可能性がある一方、複雑課題の性能はなお限定的とされる（[Yao et al., 2025](https://doi.org/10.1088/1741-2552/ae17e9)）。

### 追加すべき重要情報

**最低限区別すべき評価設計**

| 評価 | 答える問い | 実用上の意味 |
|---|---|---|
| window-random split | 同一記録内の似た窓を識別できるか | 最も楽観的。製品性能の根拠にしにくい |
| trial-grouped split | 未見の試行を同じ参加者内で識別できるか | 近接窓リークを防ぐ |
| session-independent | 同じ人の別の日に通用するか | 継続利用の最低条件 |
| participant-independent | 未見の人に通用するか | 出荷時の一般モデルの条件 |
| calibrated new-user | 新しい人の少量データで調整後に通用するか | 個人化サービスに近い |
| external dataset／site | 別施設・別機器・別課題に通用するか | 一般化の強い証拠 |
| prospective online | 時系列にリアルタイム動作するか | 実運用に最も近い |

**報告に追加すべき項目**

- 分割単位、重複窓の有無、前処理を学習fold内だけでfitしたか
- accuracyの単位がwindow、trial、session、participantのどれか
- クラス分布、balanced accuracy、macro-F1、AUC、95%信頼区間
- 対象者ごとの分布と失敗例。平均値だけでは少数者の重大な誤判定が隠れる
- ラベルの由来と評価者間一致。本人報告が得られない場合は、代理評定を真の感情と断定しない
- モデル選択と最終テストの分離、事前登録、コード・モデル・データ処理の再現可能性

**結論として追加すべき文章**

> 現在の研究は、統制されたデータセット内での分類可能性を示しているが、未見の人、別の日、異なる機器、日常環境へ通用することは別問題である。対象者独立評価や外部検証なしに、報告精度を一般利用者の感情推定精度と解釈してはならない。

## 5. 第3部 額（前額部）の脳波から得られる指標

### 判定

**個別指標の紹介は広いが、心理状態との一対一対応を弱め、前額計測の構造的限界を強調すべき。非周期成分には明確な修正が必要。**

### 正誤確認

| 指標・記述 | 判定 | 確認結果と修正案 |
|---|---|---|
| θ＝リラックス・瞑想・集中・眠気、β＝能動的思考 | 要修正 | 周波数帯は状態と一対一に対応しない。同じθ変化が課題負荷、眠気、記憶、動き、参照法などで生じる。βは感覚運動律動と筋電の双方の影響を受ける。「関連が報告されるが、文脈・部位・課題依存」とする。 |
| αは閉眼・安静で強まり、注意で弱まる | 概ね妥当 | 代表的現象だが、αは単なる休止ではなく、感覚ゲーティング、抑制、注意制御、予測にも関わる（[Klimesch, 2012](https://doi.org/10.1016/j.tics.2012.10.007)）。前額の少数電極で後頭αと同じ意味を仮定しない。 |
| FAAは接近・回避や感情の指標 | 要補足 | 仮説としては妥当だが、N=740の事前登録を含む多解析研究では、状態・特性の接近動機づけ指標としての妥当性を支持できなかった（[Paul et al., 2025](https://doi.org/10.1037/pspp0000503)）。単独の個人判定に使う根拠は不足。 |
| Fmθは前額部の指標 | 要修正 | Fmθは主にFz付近の正中前頭部活動であり、Fp1/Fp2だけの「額センサ」がFzを直接測るわけではない。電極位置、参照、体積伝導を区別する。 |
| 1/f傾斜からE/I比を推定できる | 要修正 | Gao 2017は有力な仮説を提示したが、薬理・化学遺伝学的操作では予測に反する変化もあり、非周期指数はE/I比の普遍的な指標ではない（[Salvatore et al., 2024](https://doi.org/10.1152/jn.00445.2023)）。「候補指標で機序は未確立」とする。 |
| 高周波β・γを状態指標に使う | 要補足 | 前額・側頭では筋電が同帯域に強く重なる。高周波の増加を脳活動と断定するには、EMG/EOG記録、試行除外、独立成分等の処理、感度分析が必要。 |
| 瞬きや表情筋を利用する可能性 | 妥当だが名称注意 | ケア支援の予測性能に役立つ可能性はあるが、それを「脳波由来の感情」と表示してはいけない。EEG、EOG、EMG、動作由来の寄与を分けて説明する。 |

### 追加すべき重要情報

1. **参照電極の影響**: FAA、帯域パワー、機能結合は参照法で変わる。左右差でも共通参照のノイズは消えないことがある。
2. **個人α周波数**: 固定8–13 Hzだけでなく個人のピークを考慮する方法は有用だが、前額少数チャンネルでは明瞭なαピークが得られない場合がある。
3. **スペクトル分解**: 帯域パワーは周期ピークと非周期背景が混在する。FOOOF等の分解は有用だが、推定範囲、ピーク設定、信号長、ノイズに依存する。
4. **最低限の併記項目**: サンプリング周波数、フィルタ、参照、インピーダンス／接触品質、除外率、EOG/EMG、動作、薬剤、眠気、発作、時刻。
5. **前額センサの現実的な役割**: 特定感情の直接読出しより、本人内の異常・変化・反応タイミング検出に適している可能性が高い。

## 6. 第4部 重度障害のある方の状態・快不快の評価

### 判定

**既存研究の限界を慎重に記述しており概ね妥当。2026年の系統的レビュー、対象定義、てんかん・薬剤等の交絡、個人内検証法を追加すべき。**

### 正誤確認

- 行動観察だけでも生理指標だけでも確定できない、という方向性は妥当である。重度・最重度知的障害者のメンタルヘルス問題とwell-beingの測定ツールを調べた系統的レビューでは、利用可能な尺度と心理測定学的品質が限られていた（[Flynn et al., 2017](https://doi.org/10.1016/j.cpr.2017.08.006)）。
- 小規模な個別研究の結果は、存在証明としては有用だが、一般化の根拠にはならない。例えば心拍・動作と機械学習を用いた研究はPIMD当事者2名であり、個人プロファイルの可能性を示す段階である（[Hammann et al., 2024](https://doi.org/10.1080/20473869.2022.2154928)）。
- 好きな音楽や自分の名前に対するEEG反応は、刺激認識、注意、覚醒、予測違反を反映し得る。「認識反応がある」ことから「快である」ことへは直接進めない。
- 意識障害（VS/UWS、MCS）の研究結果はPIMD／重症心身障害へそのまま外挿できない。病態、意識状態、年齢、感覚入力、薬剤が異なるため、別集団として扱うべきである。

### 最優先で追加すべき最新知見

Vandesandeらの2026年系統的レビューは、2008–2025年の5,495レコードから34研究を採択し、眼球運動、ウェアラブル、生体温度、EEG等が、注意、社会情動的関与、情動反応の研究に用いられていたと報告した。心理生理指標は行動や代理報告で見えない反応を捉え得る一方、信頼性、方法の標準化、対象者を包摂する研究設計が未成熟である（[Vandesande et al., 2026](https://doi.org/10.1111/jar.70222)）。

これは元文書の「直接証拠は乏しい」という結論を覆すものではないが、「関連研究はほぼない」から「34研究の蓄積はあるが、異質性が大きく、実用精度は未確立」へ更新する材料になる。

### 追加すべき交絡要因

- てんかん、発作間欠期放電、発作後状態
- 抗てんかん薬、鎮静薬、筋弛緩薬、抗コリン薬等
- 睡眠・覚醒、疲労、痛み、便秘、逆流、呼吸、SpO2、体温
- 痙縮、ジストニア、不随意運動、表情筋、吸引・体位変換
- 視覚・聴覚障害、刺激が本人に届いているか
- 頭蓋・皮膚・毛髪、電極接触、個人の背景EEG

脳性麻痺児・青年のてんかん有病率を調べた72研究・53,969人のメタ解析では、統合値は38.0%であり、EEG異常、重度知的障害、四肢麻痺等と関連した（[Gong et al., 2023](https://doi.org/10.3389/fped.2023.1189648)）。これはEEGを感情推定へ用いる際の交絡・安全管理として重要である。

### 推奨する研究設計

1. 本人ごとのN-of-1反復デザインを基本にする。
2. 「快」「不快」だけでなく、覚醒、痛み、注意、発作疑い、測定不良を別ラベルにする。
3. 支援者の注釈者を複数にし、刺激条件を伏せた評定と一致度を記録する。
4. 本人の普段のサイン、選好、拒否、体調を事前にプロファイル化する。
5. 日をまたいだ再現性と、介入を変えたときの前向きな予測性能を確認する。
6. 出力は確定診断ではなく、「いつもと違うため再確認」の通知として評価する。

## 7. 第5部 脳波以外の信号（概要）

### 判定

**方向性は妥当。ただし、各信号の非特異性と、マルチモーダル化だけではラベルの問題が解決しないことを追加すべき。**

### 正誤確認

- 心拍、HRV、EDA、表情、視線、動作は情動・覚醒に関連し得る。しかし、同じ変化が運動、姿勢、呼吸、痛み、発熱、薬剤、注意、驚きでも起こるため、一つの感情を特異的に示すものではない。
- 202研究のメタ解析では、自律神経変化のパターンは感情カテゴリを明確に分離せず、カテゴリ内の異質性も大きかった（[Siegel et al., 2018](https://doi.org/10.1037/bul0000128)）。「心拍が上がったから喜び／不快」といった推論は避けるべきである。
- EDAは交感神経性の覚醒変化に敏感だが、valenceの符号を単独では決めにくい。
- LF/HFを単純な「交感神経／副交感神経バランス」とみなす説明は修正が必要。LFは交感・副交感の双方と圧受容反射の影響を受け、LF/HFの生理学的解釈には強い限界がある（[Billman, 2013](https://doi.org/10.3389/fphys.2013.00026)）。

### 追加すべき重要情報

- 呼吸数・呼吸相、SpO2、体温、PPG信号品質、姿勢、加速度、発声・声量、瞳孔、環境音、介助イベントを候補に含める。
- マルチモーダル融合では、時計ずれ、欠損、装着ずれ、異なる時間応答、学習時と運用時のセンサ欠落を検証する。
- センサを増やすほど負担、誤作動、プライバシー侵害も増える。性能差が小さい場合は、より負担の少ない構成を選ぶ。
- 「脳由来」「自律神経由来」「行動由来」「文脈由来」を説明可能な形で分け、各モダリティを除いた感度分析を行う。
- 本人内で再現する変化があるかを先に確認し、その後に機械学習を使う。大量の窓を作って見かけのサンプル数を増やしても、独立な参加者数や日数は増えない。

## 9. 第7部 倫理

### 判定

**主要原則は正確。CIOMSの例外規定、同意能力の捉え方、神経・認知データのプライバシー、誤判定によるケア上の害を追加すべき。**

### 正誤確認

- 2024年ヘルシンキ宣言の第20項、第28項、第29項の要約は概ね正しい（[WMA公式](https://www.wma.net/policies-post/wma-declaration-of-helsinki/)）。本人の価値・選好、法定代理人の許可、可能な範囲のassent、dissentの尊重を含む。
- CIOMS Guideline 16の要約には重要な但し書きが抜けている。本人への直接利益がない手続きは原則として最小リスク以下だが、社会的価値が切実で、同意能力のある人では実施できない場合、倫理審査委員会が**最小リスクをわずかに上回る増加**を認め得る（[CIOMS 2016公式PDF](https://cioms.ch/wp-content/uploads/2017/01/WEB-CIOMS-EthicalGuidelines.pdf)）。「必ず最小リスク以下」と断定しない。
- 同意能力は診断名や後見の有無だけで決めず、意思決定の内容、時点、支援方法に応じて評価する。理解可能な形式、時間、慣れた支援者、コミュニケーション手段を提供した上で判断する。

### 追加すべき重要情報

1. **継続的assent／dissent**: 一度の代諾で終了せず、装着拒否、表情、身体のこわばり、逃避、苦痛サインを継続的に確認し、中止基準を事前に定める。
2. **誤判定の害**: 「快」と誤判定して苦痛を見逃す偽陰性と、「不快」と誤判定して本人の活動・選択を制限する偽陽性の双方を評価する。感情スコアのみでケアを自動決定しない。
3. **データ最小化**: 生EEG、映像、音声、行動、位置、介助記録の全てを集める設計は、再識別や精神状態推測のリスクが高い。必要な信号だけを収集し、保存期間、アクセス、二次利用、削除を明示する。
4. **認知バイオメトリクス**: リスクは狭義の神経データに限らず、眼球、声、行動、ウェアラブルから推定される認知・情動状態にも及ぶ（[Magee et al., 2024](https://doi.org/10.1016/j.neuron.2024.09.004)）。
5. **研究登録と結果公開**: ヘルシンキ宣言の登録・結果公表原則に沿い、否定的結果、失敗率、装着不能例も公開する。
6. **当事者・家族・支援者参画**: 研究課題、負担、表示語、誤判定時の対応、結果の返却を、当事者の意思を中心に共同設計する。
7. **偶発所見**: 発作様活動や健康異常を検出した場合の確認・連絡・医療相談経路を、研究開始前に定める。感情推定アルゴリズムは診断機器ではないことも明示する。

## 10. 付録A 民生用・ウェアラブル脳波の検証状況

### 判定

**多数の検証研究を適切に収集している。ただし、「研究利用の多さ」と「目的に対する妥当性」を明確に分離し、2026年の比較研究を追加すべき。**

### 正誤確認

- Sabioらのスコーピングレビューが916報を同定したことは正しい（[Sabio et al., 2024](https://doi.org/10.1371/journal.pone.0291186)）。ただし内訳は雑誌531報、会議385報で、レビューの目的は利用範囲の把握であり、全製品・全用途の質を保証するものではない。
- 同レビューでデバイス検証に分類された研究は全体の6.18%にすぎない。大量に「使用された」ことを、感情推定の妥当性と同一視してはいけない。
- α律動、ERP、SSVEP等を検出できることは信号妥当性の証拠にはなるが、独自の「calm」「attention」「emotion」スコアの構成概念妥当性を直接証明しない。
- Museと研究用装置の高い相関を報告するCannard 2021はbioRxiv査読前版であり、査読誌の証拠と同じ重みで扱わない方がよい。

### 追加すべき2026年研究

30名を対象にBrainLink Pro、NeuroNicle FX2、MindWave Mobile2、Muse2を研究用DSI-24と比較した研究では、瞬き、顎の収縮、開閉眼、頭部運動を含む構造化評価を行い、全機器で非神経性アーチファクトと脳波信号を検出し、α特性とノイズ頑健性の一部で研究用装置と比較可能だった。一方、これは特定課題下の信号評価であり、感情ラベルの妥当性を検証した研究ではない（[Lee et al., 2026](https://doi.org/10.1038/s41598-026-39056-8)）。

### 検証を5段階に分ける提案

1. **装置信頼性**: 接触、欠損、バッテリー、無線遅延、イベント同期、再装着
2. **信号妥当性**: 研究用装置との同時記録、α、ERP、SSVEP、アーチファクト
3. **特徴量信頼性**: 日内・日間再検査、参照法、個人差、動作中
4. **構成概念妥当性**: スコアが本当に快、不快、注意、ストレス等を測るか
5. **臨床・ケア有用性**: 判断、QOL、見逃し、負担が改善するか

対象文書の付録Aは主に1〜3を扱っている。想定サービスに必要なのは4と5であり、ここが最も不足している、と明記すべきである。

## 11. 付録B 用語集

### 判定

**有用だが、初心者向けの単純化が誤概念につながる項目がある。以下を差し替えるべき。**

### 修正推奨用語

| 用語 | 修正案 |
|---|---|
| 脳波（EEG） | 頭皮上の電極間で記録する電位差。大脳皮質由来の活動に、体積伝導、眼電、筋電、動作、電極・環境ノイズが重なる。 |
| チャンネル | 装置が記録する電位差信号の系列。電極数、参照・接地電極数、保存チャンネル数は装置構成により一致しない。 |
| δ・θ・α・β・γ | 慣用的な周波数帯。境界は研究ごとに異なり、各帯域が一つの心理状態に対応するわけではない。 |
| p値 | 帰無仮説と統計モデルを仮定したとき、観測値以上に極端なデータが得られる確率。仮説が正しい確率や、結果が偶然である確率ではない。 |
| チャンス | 評価指標・クラス比・予測規則に依存する基準。均衡したKクラスの単純accuracyでは1/Kだが、不均衡では多数派基準や置換検定等が必要。 |
| accuracy | 全予測中の正解割合。window、trial、session、participantのどの単位で計算したかと、クラス比を併記する。 |
| F1 | 適合率と再現率の調和平均。macro、micro、weighted等があり、不均衡に常に「強い」とは限らない。 |
| AUC | 多くの場合ROC-AUC。二値分類で0.5がランダム順位相当。強い不均衡ではPR-AUCも確認する。 |
| FAA | 左右前頭αパワーの差として計算される候補指標。計算式、電極、参照、状態に依存し、個人の接近動機や快不快を確定する指標ではない。 |
| 非周期指数 | パワースペクトルの非周期背景の傾き。覚醒、年齢、薬剤等と関連するが、E/I比を一意に示す確立済み指標ではない。 |
| LF/HF | HRVの周波数成分比。単純な交感／副交感バランスとしての解釈には限界がある。 |
| ラベル | 学習上の正解として扱う値。本人報告、刺激カテゴリ、代理評定、観察、生理基準は互換ではなく、測定誤差を含む。 |
| PIMD | 最重度知的障害と重い運動・複合障害を指す研究用語。国際的に完全統一された境界はなく、研究ごとに対象を操作的に記述する。 |
| BCI | 脳活動を用いて外部機器を操作・通信する仕組み。状態を暗黙に推定しシステムを適応させるpassive BCIを含む場合がある。 |

### 追加推奨用語

- **構成概念妥当性**: そのスコアが名付けられた概念を本当に測る程度
- **外部妥当性**: 別の人、日、施設、機器、日常環境に結果が通用する程度
- **再検査信頼性**: 同じ対象を別の時間に測ったときに結果が再現する程度
- **対象者独立評価**: テスト対象者のデータを学習・調整に一切使わない評価
- **個人内評価**: 同一人物の別試行・別日への予測を評価する方法
- **不確実性／棄却**: 自信のない出力を無理に分類せず「判定不能」とする仕組み
- **感度・特異度・陽性的中率**: 見逃しと誤警報を用途に即して評価する指標
- **データセットシフト**: 学習時と運用時で人、機器、環境、ラベル分布が変わること
